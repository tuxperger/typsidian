## Default Permission

Очередь захватов «Поделиться», возврат в исходное приложение и события ярлыков

#### This default permission set includes the following:

- `allow-pending`
- `allow-resolve`
- `allow-return-to-source`
- `allow-image`
- `allow-register-listener`
- `allow-remove-listener`
