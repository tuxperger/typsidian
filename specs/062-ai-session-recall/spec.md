# Feature Specification: Припоминание в начале урока

**Feature Branch**: `062-ai-session-recall`

**Created**: 2026-11-02

**Status**: Draft

**Priority**: P3

**Summary**: Продолжая урок или начиная новый по знакомой теме, я сначала за минуту вспоминаю пройденное — пару вопросов «в прошлый раз мы…» — и только потом иду дальше.

**Input**: User description: "Из LearnHarness (vision: «сессии открываются припоминанием» — 60-секундная карточка из пройденного перед новым материалом, зерно интервального повторения, без геймификации)."

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из конституции и спек 051–054.

- Q: Обязательно ли припоминание? → A: Нет. Его можно пропустить одним действием и
  выключить в настройках; по умолчанию оно включено для продолжения урока после перерыва
  от суток.
- Q: Ведётся ли расписание повторений или счёт? → A: Нет: ни расписаний, ни очков, ни
  серий. Итог припоминания — сведения внутри урока (как у практики 053).
- Q: Откуда вопросы? → A: Из уже пройденных шагов этого урока, а при новом уроке — из
  утверждений графа 054, близких к цели по локальному поиску, если граф включён.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Вспомнить перед продолжением (Priority: P1)

Пользователь открывает урок, прерванный вчера. Перед продолжением учитель задаёт 1–3
коротких вопроса на припоминание пройденного без подсказок. После ответов — короткий итог
и продолжение с того же места.

**Why this priority**: суть фичи.

**Independent Test**: открыть урок, последний шаг которого старше суток, и получить
карточку припоминания до продолжения.

**Acceptance Scenarios**:

1. **Given** последний шаг урока старше суток, **When** пользователь продолжает урок,
   **Then** сначала появляется карточка «Вспомним» с вопросом по пройденному.
2. **Given** карточка показана, **When** пользователь нажимает «Пропустить», **Then** урок
   продолжается без вопросов, это отмечено в уроке.
3. **Given** ответ выдаёт забытое, **When** учитель продолжает, **Then** он коротко
   повторяет забытое до нового материала.
4. **Given** последний шаг моложе суток, **When** урок продолжается, **Then** карточки нет.

---

### User Story 2 - Припоминание в новом уроке (Priority: P3)

Новый урок по теме, близкой к пройденному: учитель начинает с вопроса по связанным
утверждениям графа знаний.

**Why this priority**: требует графа 054; полезно, но не обязательно.

**Independent Test**: при включённом графе начать урок по теме, по которой есть
утверждения, и получить вопрос по ним.

**Acceptance Scenarios**:

1. **Given** граф содержит утверждения, близкие к цели, **When** начинается новый урок,
   **Then** первая карточка — припоминание по ним, и в уроке видно, какие утверждения ушли
   модели.
2. **Given** граф выключен или пуст, **When** начинается новый урок, **Then** карточки нет.

### Edge Cases

- Урок завершён: припоминание не предлагается.
- Нет сети: карточка не появляется, урок открывается как обычно; ничего не теряется.
- Пользователь закрыл урок посреди припоминания: при следующем открытии карточка не
  повторяется, если на неё уже был ответ.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: При продолжении урока после перерыва не короче порога (по умолчанию сутки)
  урок MUST начинаться с 1–3 вопросов на припоминание пройденного в этом уроке.
- **FR-002**: Припоминание MUST пропускаться одним действием и выключаться в настройках;
  порог MUST настраиваться.
- **FR-003**: Вопросы MUST касаться только пройденного и MUST NOT содержать подсказку
  ответа в формулировке.
- **FR-004**: Забытое MUST кратко повторяться до нового материала.
- **FR-005**: Для нового урока при включённом графе 054 припоминание MAY строиться по
  близким утверждениям; отправленные утверждения MUST быть видны в уроке и журнале.
- **FR-006**: Приложение MUST NOT вести расписания повторений, очки, серии и иные
  показатели вне файла урока.
- **FR-007**: Без сети или при отказе провайдера урок MUST открываться без припоминания.
- **FR-008**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Припоминание**: вопросы, ответы, итог, отметка «пропущено»; часть файла урока.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Припоминание занимает не больше 3 вопросов и в среднем не дольше 2 минут.
- **SC-002**: Пропуск — 1 действие.
- **SC-003**: Вне файлов уроков не появляется ни одной записи о результатах припоминания.

## Assumptions

- Зависит от 051; граф — 054; формат вопросов — как у 051.
