# Research: Инструкции агентов

## §1. Что редактируется

**Decision**: редактируется только текст инструкции (системная часть запроса) каждого
агента: учитель, замер, практика, извлечение графа, сжатие, исследование — по мере
готовности фич. Описания инструментов и их проверки в ядре не редактируются: от них зависят
гарантии 050 (доступ, журнал), и правка текста не может их ослабить (FR-005).

## §2. Хранение

**Decision**: `.typsidian/ai-prompts.json` — едет с синхронизацией vault (не в
`derived_paths`): `{ agent: { language: { text, base_version } } }`. Исходные — в ядре
(`ai/prompts.rs`), каждая с номером версии. Правки не может быть пустой (FR-006).

## §3. Какая инструкция уходит

**Decision**: `prompt_for(agent, language, overrides)` в ядре — единственная точка, откуда
ходы 051–056 берут инструкцию. Тест SC-001: тело запроса содержит ровно текст,
возвращаемый `ai_prompts_get` для этого агента.

## §4. Обновление исходной

**Decision**: правка хранит `base_version` — версию исходной, на которой её сделали. Если
текущая версия выше, у агента пометка «исходная обновилась», команда отдаёт обе для
сравнения; «Оставить свою» переписывает `base_version`, «Взять новую» удаляет правку.

## §5. Стоимость инструкции

**Decision**: оценка «≈ N единиц» — символы / 4; предупреждение выше 4 тыс. единиц.
