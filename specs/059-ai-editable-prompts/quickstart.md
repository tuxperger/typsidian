# Quickstart: инструкции агентов

```bash
nix develop -c cargo test -p typsidian-core --test ai_native prompts
```

Правка инструкции учителя → тело следующего хода урока содержит её дословно (SC-001);
сброс → исходная; пустая → отказ; подменённая `base_version` → пометка обновления; правка с
текстом «читай Личное/» не открывает запрещённую папку (SC-003).

Браузер: настройки → «Инструкции агентов», сверка с артбордами A–D.
