# Research: Отказ от внешнего модального редактора

## 1. Принцип V конституции

**Decision**: принцип V остаётся под своим номером и становится «Внешние процессы — зона
повышенного риска»: любая работа, затрагивающая интеграцию с внешним процессом (системный
`ssh`, локальный API Syncthing, будущие), проходит отдельный `/speckit-clarify` до плана.
Список санкционированных интеграций теряет удалённый пункт. Версия 1.2.0 → 2.0.0
(переопределение принципа).
**Rationale**: номера VI–X упоминаются в Constitution Check всех 25 спек; сдвиг сделал бы
их ложными. Риск внешних процессов реален и без удалённого моста (`ssh`, Syncthing).
**Alternatives**: удалить V и перенумеровать — ломает ссылки; оставить «V. —
исключён» — пустой принцип ничего не регулирует.

## 2. Что удаляется из ядра

**Decision**: модуль `settings::editor_mode` целиком; `ModePreference`, поля
`editor_mode_preference` и `editor_config_path` в `Settings`, `SettingsChange` и настройках
vault; события `EditorModeChanged`, `EditorConfigDiskStateChanged` и записи журнала о них;
поля режима в диагностике; предусловия смены режима — `ApplyContext`,
`ApplyPlan::RequiresNoteSave`, `RejectReason::{SaveFailed, UnresolvedConflict}`:
кроме смены режима их никто не порождал. Фича `test-support` остаётся, если ею
пользуется что-то кроме тестовой заглушки моста; иначе — удаляется вместе с ней.
**Rationale**: заглушки без реализации — ложное обещание в типах и UI.

## 3. Чтение и запись старых файлов

**Decision**: разбор `Settings` и настроек vault и так игнорирует незнакомые ключи
(serde без `deny_unknown_fields`) — FR-004 выполняется сам. Запись переносит незнакомые
ключи как есть (format.rs, «Ключи, которых приложение не знает, переносятся»), поэтому
два устаревших ключа явно удаляются при записи — список `RETIRED_KEYS` в обоих форматах,
с тестом (FR-005).
**Rationale**: перенос незнакомых ключей нужен для более новых версий; удалённые ключи —
известное прошлое, им переноситься незачем.

## 4. UI

**Decision**: из раздела «Сочетания клавиш» уходит блок режима; из «Дополнительно» —
строки режима; из статус-бара — `ts-vim`; `applyWithNoteSave` удаляется, настройки
применяются прямым вызовом. Порт вставки заготовок (003) остаётся, реализация
переименовывается из «ввод без раскладки» в «редактор» без изменения поведения.

## 5. Документация прежних фич

**Decision**: упоминания в `specs/001…025` правятся: строки Constitution Check
«V. Мост … N/A» → «V. Внешние процессы … N/A» (или по существу, где процессы есть — 011);
абзацы, описывающие мост, удаляются или сводятся к «внешнего редактора нет». Спека 004
получает пометку в шапке о том, что US/FR режима отменены фичей 026.
