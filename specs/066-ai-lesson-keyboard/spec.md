# Feature Specification: Урок с клавиатуры

**Feature Branch**: `066-ai-lesson-keyboard`

**Created**: 2026-11-02

**Status**: Draft

**Priority**: P3

**Summary**: Урок и практику можно пройти, не касаясь мыши: цифрами выбрать вариант, клавишами — уверенность, переходить между вопросами и полями, а подсказка показывает все сочетания.

**Input**: User description: "Из LearnHarness (keyboard.md: карта клавиш, работа в раскладках, Tab по полям, Esc действует на текущий элемент; release 0.3: навигация по вопросам клавишами, j/k)."

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из спек 004 (настройки,
переназначение сочетаний), 045 (режим Vim) и 051.

- Q: Переназначаются ли сочетания урока? → A: Глобальные — да, через существующие настройки
  сочетаний 004. Клавиши внутри карточки вопроса (цифры, уверенность) закреплены и
  показываются как «часть экрана».
- Q: Работают ли сочетания в русской раскладке? → A: Да: сочетания с модификаторами
  сопоставляются по физической клавише, как уже принято в приложении.
- Q: Как Esc сочетается с остановкой ответа (051)? → A: Esc действует на ближайший
  элемент: сначала поле, меню или диалог; только когда их нет — останавливает ответ
  учителя.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Ответить с клавиатуры (Priority: P1)

На вопросе с вариантами пользователь нажимает цифру варианта, клавишу уверенности, Tab в
поле «думаю вслух», пишет и отправляет `Mod+Enter`.

**Why this priority**: суть фичи.

**Independent Test**: пройти три вопроса урока только клавиатурой.

**Acceptance Scenarios**:

1. **Given** открыт вопрос с вариантами и фокус не в поле ввода, **When** пользователь
   нажимает «2», **Then** выбран второй вариант.
2. **Given** вопрос открыт, **When** пользователь нажимает клавишу уверенности, **Then**
   уверенность отмечена.
3. **Given** фокус в поле, **When** пользователь печатает цифры, **Then** они попадают в
   текст, а не выбирают вариант.
4. **Given** открыт диалог, **When** пользователь нажимает Esc, **Then** закрывается
   диалог, а ответ учителя не останавливается.

---

### User Story 2 - Переходы и подсказка (Priority: P2)

Клавишами пользователь переходит к предыдущему и следующему вопросу ленты (в том числе
j/k в режиме Vim 045), открывает план 052, вид графа 054, а «?» показывает все сочетания
урока.

**Why this priority**: удобство длинных уроков.

**Independent Test**: перейти к первому вопросу урока клавишей и открыть подсказку «?».

**Acceptance Scenarios**:

1. **Given** урок с 10 вопросами, **When** пользователь нажимает «предыдущий вопрос»,
   **Then** лента прокручивается к нему, вопрос выделен.
2. **Given** фокус не в поле, **When** пользователь нажимает «?», **Then** открывается
   подсказка сочетаний урока; Esc её закрывает.
3. **Given** включён режим Vim 045, **When** пользователь нажимает j/k вне поля, **Then**
   переходит к следующему/предыдущему вопросу.

### Edge Cases

- Вариантов больше девяти: цифрами выбираются первые девять, остальные — стрелками.
- Сочетание урока совпадает с переназначенным пользователем глобальным: побеждает
  назначение пользователя, подсказка показывает фактическое.
- Android с аппаратной клавиатурой: те же сочетания.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Все действия урока и практики MUST быть доступны с клавиатуры.
- **FR-002**: Вне полей ввода цифры MUST выбирать варианты, отдельные клавиши — уверенность;
  в полях ввода они MUST печататься.
- **FR-003**: Tab MUST переходить по полям урока по порядку: ответ, рассуждение, вставка.
- **FR-004**: Esc MUST действовать на ближайший открытый элемент и только без них —
  останавливать ответ учителя.
- **FR-005**: Глобальные сочетания урока MUST переназначаться в настройках 004 и MUST NOT
  занимать уже занятые сочетания.
- **FR-006**: «?» вне полей MUST открывать подсказку сочетаний урока.
- **FR-007**: В режиме Vim 045 j/k MUST переходить между вопросами.
- **FR-008**: Сочетания с модификаторами MUST работать в русской раскладке.
- **FR-009**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Сочетание урока**: действие, клавиши, закреплено или переназначаемо.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Урок из 5 вопросов проходится без мыши (проверка сценарием браузера).
- **SC-002**: 0 конфликтов с занятыми сочетаниями приложения.

## Assumptions

- Зависит от 051; план — 052, граф — 054, режим Vim — 045, сочетания — 004.
