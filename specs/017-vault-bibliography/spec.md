# Feature Specification: Библиография vault

**Feature Branch**: `017-vault-bibliography`

**Created**: 2026-10-10

**Status**: Draft

**Priority**: P2

**Summary**: Источники vault лежат в одном месте: цитата вставляется поиском по автору и названию, а у каждого источника видно, какие заметки его цитируют.

**Input**: User description: "Библиография vault. Общий .bib или Hayagriva-файл, вставка цитаты поиском по автору и названию, список заметок, цитирующих источник."

## Термины

- **Файл источников** — файл в vault со списком источников в одном из форматов, которые
  понимает Typst (BibTeX `.bib`, Hayagriva `.yml`).
- **Источник** — одна запись файла источников: ключ, авторы, название, год и прочее.
- **Цитата** — место в заметке, ссылающееся на источник по ключу.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Вставить цитату поиском (Priority: P1)

Пользователь вызывает «Вставить цитату», набирает часть фамилии или названия, выбирает
источник из списка — в текст подставляется цитата с его ключом. Запоминать ключи не
нужно.

**Why this priority**: Основная польза: сейчас ключ нужно помнить или искать в файле
источников глазами.

**Independent Test**: В vault с файлом источников на 200 записей вызвать вставку цитаты,
набрать «кнут», выбрать запись; убедиться, что в тексте стоит цитата с её ключом и
документ собирается со ссылкой на источник.

**Acceptance Scenarios**:

1. **Given** vault с файлом источников, **When** пользователь вызывает вставку цитаты и
   набирает текст, **Then** видит источники, у которых он встречается в авторах,
   названии, годе или ключе, с этими полями в строке списка.
2. **Given** выбран источник, **When** пользователь подтверждает, **Then** в месте
   каретки появляется цитата с его ключом.
3. **Given** заметка ещё не подключает файл источников, **When** вставлена первая
   цитата, **Then** приложение предлагает добавить в заметку список литературы и по
   согласию добавляет его; без согласия вставляется только цитата.
4. **Given** в vault нет файла источников, **When** пользователь вызывает вставку
   цитаты, **Then** ему предлагают создать файл или указать существующий.

---

### User Story 2 - Видеть, где источник процитирован (Priority: P2)

Пользователь открывает список источников vault, выбирает источник и видит заметки, в
которых он процитирован, с переходом к месту цитаты.

**Why this priority**: Превращает файл источников в рабочий инструмент: по источнику
находятся все свои заметки о нём.

**Independent Test**: Процитировать один источник в двух заметках, открыть его в списке;
убедиться, что обе заметки указаны и переход ведёт к цитате.

**Acceptance Scenarios**:

1. **Given** источник процитирован в нескольких заметках, **When** пользователь выбирает
   его, **Then** видит эти заметки с фрагментами вокруг цитаты и переходит к месту
   цитаты по клику.
2. **Given** в списке источников включён показ непроцитированных, **When** список
   показан, **Then** видны источники, на которые не ссылается ни одна заметка.

---

### User Story 3 - Не терять цитаты при правке источников (Priority: P3)

Пользователь правит файл источников — в приложении или извне. Цитаты с ключами, которых
больше нет, отмечаются в редакторе до сборки, а список источников обновляется сам.

**Why this priority**: Защита от тихой поломки документа; основной сценарий работает и
без неё.

**Independent Test**: Удалить из файла источников запись, процитированную в открытой
заметке; убедиться, что цитата отмечена как указывающая в никуда.

**Acceptance Scenarios**:

1. **Given** файл источников изменён, **When** приложение замечает изменение, **Then**
   список источников и подсказки при вставке отражают новое содержимое.
2. **Given** ключ цитаты отсутствует в файле источников, **When** заметка открыта,
   **Then** цитата отмечена, и названа причина.
3. **Given** файл источников содержит запись с ошибкой, **When** он читается, **Then**
   остальные записи доступны, а ошибочная названа с местом в файле.

---

### Edge Cases

- Несколько файлов источников в vault: все участвуют в поиске; при совпадении ключей в
  разных файлах пользователь видит оба источника и файл каждого.
- Очень большой файл источников (10 000 записей): поиск остаётся мгновенным на глаз.
- Ключ с пробелами или знаками, недопустимыми в краткой записи цитаты: вставляется в
  записи, которую Typst принимает.
- Файл источников лежит вне vault: не поддерживается, пользователю предложено положить
  его в vault.
- Vault только на чтение: поиск и вставка цитаты работают, создание файла источников —
  нет.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Система MUST находить в vault файлы источников поддерживаемых форматов и
  читать из них источники.
- **FR-002**: Пользователь MUST иметь возможность найти источник по авторам, названию,
  году и ключу и вставить цитату на него в место каретки.
- **FR-003**: Вставленная цитата MUST быть записью, которую Typst принимает для любого
  допустимого ключа.
- **FR-004**: Если заметка не подключает список литературы, система MUST предложить
  добавить его и MUST NOT добавлять без согласия.
- **FR-005**: Система MUST показывать список источников vault и для каждого — заметки,
  в которых он процитирован, с переходом к месту цитаты.
- **FR-006**: Система MUST отмечать в редакторе цитаты, ключ которых не найден ни в одном
  файле источников.
- **FR-007**: Список источников MUST обновляться при изменении файлов источников в
  приложении и вне его.
- **FR-008**: Ошибка в одной записи MUST NOT делать недоступными остальные; ошибочная
  запись MUST быть названа с местом в файле.
- **FR-009**: Всё MUST работать без сети; содержимое источников и заметок MUST NOT
  покидать устройство (принципы VII, IX).
- **FR-010**: Поведение MUST быть одинаковым во всех оболочках (принцип II); тексты —
  из переводов (010).

### Key Entities

- **Источник**: ключ, авторы, название, год, вид, файл, в котором записан.
- **Цитата**: заметка, место в тексте, ключ источника.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Вставка цитаты на известный пользователю источник занимает не больше
  10 секунд и не требует открывать файл источников.
- **SC-002**: Результаты поиска по 10 000 источников появляются не позже чем через
  200 мс после нажатия клавиши.
- **SC-003**: 100 % цитат с несуществующим ключом отмечены до сборки документа.
- **SC-004**: Список заметок, цитирующих источник, открывается не позже чем через
  1 секунду в vault из 5 000 заметок.

## Вне скоупа

- Редактор записей источников с формой по полям.
- Импорт источников по DOI, ISBN или из менеджеров литературы.
- Хранение и чтение PDF источников.
- Выбор стиля оформления списка литературы из интерфейса.

## Assumptions

- Зависит от 001, 005, 008 (вставка элементов), 010; сведения о цитатах строятся так же
  локально, как сведения о ссылках.
- Форматы файлов источников — те, что принимает Typst; своего формата приложение не
  вводит.
