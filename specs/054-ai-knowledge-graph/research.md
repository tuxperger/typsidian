# Research: Граф знаний из уроков

## §1. Где лежит граф

**Decision**: папка `<lessons_folder>/Граф знаний/` (по умолчанию `Уроки/Граф знаний/`), три
файла JSON Lines, только дописывание: `propositions.jsonl` (утверждения и их формулировки),
`chains.jsonl` (цепочки), `sources.jsonl` (источники, покрытие и удаления). Вид файла —
`Other`: в дереве не виден, но это обычные файлы vault, синхронизируются и читаются без
приложения (FR-006, конституция «Провайдеры моделей»).

**Rationale**: дописывание объединяется синхронизацией без перезаписи; конфликт — как у
заметок (011). Удаление — строка-«надгробие», а не переписывание файла.

## §2. Извлечение

**Decision**: задание извлечения берёт из урока объяснения учителя (`Teacher.text`), ещё не
покрытые (`sources.jsonl` хранит номер последнего покрытого события урока), пачками до
20 тыс. символов. Модель получает: объяснения с номерами событий и до 50 существующих
утверждений, найденных локальным поиском по словам пачки (принцип IX: поиск локальный).
Инструмент `submit_findings { propositions: [{ key, text, same_as? }], chains: [{ premises:
[key|id], conclusion: key|id, event }] }`. Ответы и рассуждения пользователя не попадают в
запрос (FR-002) — проверяется тестом по телу запроса.

## §3. Объединение без дублей

**Decision**: утверждение получает id `p_<hash нормализованного текста>`; `same_as`
указывает на существующий id — новая формулировка дописывается к нему. Цепочка — id
`c_<hash отсортированных посылок + вывода>`. Повтор той же пачки даёт те же id — 0 дублей
(SC-002). Ссылка на несуществующее — цепочка отклоняется (Edge Case).

## §4. Фоновое задание

**Decision**: реестр заданий в ядре (`ai/knowledge/jobs.rs`) по образцу буфера прогресса 051:
состояние, пачки, отмена через `cancel` 050. Интерфейс опрашивает `ai_knowledge_jobs`.
Автоматический запуск — после хода учителя, если включено (`knowledge_auto`), и только
когда непокрытого текста больше 2 тыс. символов. Урок задание не ждёт (FR-004).

## §5. Отображение

**Decision**: карта — `GraphCanvas` и воркер раскладки графа заметок 025: ядро отдаёт узлы
(утверждения, плюс узел-развилка для цепочки из нескольких посылок), рёбра и группы по
источнику в той же форме, что `VaultGraph`. Таблица цепочек — отдельный компонент. Поиск —
локальный, по формулировкам (FR-007).

## §6. Чтение графа агентом и выбор пользователя

**Decision**: настройки `knowledge_agent_reads` (по умолчанию выкл.) и `knowledge_map`
(вкл.). Выбор утверждений при старте замера 052 и практики 053 — событие `Material` с
текстом утверждений и цепочек. Чтение агентом — инструмент `read_knowledge { query }` с
локальным поиском, до 30 утверждений, событие `KnowledgeRead` видно в уроке и журнале.
Папка графа в запрещённых — оба пути отказывают (Edge Case).

## §7. Удаление

**Decision**: удаление утверждения — надгробие в `propositions.jsonl`; цепочки, где оно
посылка, показываются неполными, где вывод — скрываются. Удаление вклада источника —
надгробие источника в `sources.jsonl`: его утверждения без других источников скрываются.
Удаление урока с «оставить вклад» помечает источник `removed`.
