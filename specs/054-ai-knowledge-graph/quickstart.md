# Quickstart: граф знаний

```bash
nix develop -c cargo test -p typsidian-core --test ai_native knowledge
```

Поддельный поток `submit_findings`: урок из трёх объяснений → утверждения с источником;
повтор — 0 дублей; `same_as` объединяет; висячая цепочка отклонена; тело запроса не
содержит ответов пользователя; удаление утверждения делает цепочку неполной.

Браузер: `scripts/dev/scenarios/ai-knowledge.mjs` — урок, пополнение, карта, таблица,
переход к источнику; сверка с артбордами A–F.
