# Feature Specification: Выбор пути на развилке плана

**Feature Branch**: `064-ai-plan-branch-choice`

**Created**: 2026-11-02

**Status**: Draft

**Priority**: P3

**Summary**: Когда к цели ведут два пути — например, через геометрию или через алгебру, — учитель показывает развилку на плане, а выбираю путь я.

**Input**: User description: "Из LearnHarness (vision: «шаги открываются по проверке; на развилках ученик выбирает ветку — два пути отсюда, выбери»)."

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из спеки 052.

- Q: Может ли учитель выбрать сам? → A: Только если пользователь нажал «Выбери за меня»;
  иначе урок ждёт выбора.
- Q: Пропадает ли невыбранная ветка? → A: Нет, остаётся на плане как «не выбрано»; к ней
  можно вернуться позже, и учитель перестроит план.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Выбрать ветку (Priority: P1)

На развилке учитель описывает два–три пути одной фразой каждый; на плане они показаны
ветками. Пользователь выбирает — урок идёт по выбранной.

**Why this priority**: суть фичи.

**Independent Test**: заготовленный ответ модели с развилкой → карточка выбора → выбор →
план отмечает выбранную ветку.

**Acceptance Scenarios**:

1. **Given** учитель предложил развилку, **When** пользователь видит урок, **Then** карточка
   выбора показывает пути с описанием, а план — ветки.
2. **Given** пользователь выбрал путь, **When** урок продолжается, **Then** шаги выбранной
   ветки становятся следующими, невыбранные помечены «не выбрано».
3. **Given** пользователь нажал «Выбери за меня», **When** учитель отвечает, **Then** он
   выбирает и называет причину.

---

### User Story 2 - Вернуться к другой ветке (Priority: P3)

После цели пользователь выбирает невыбранную ветку на плане — учитель ведёт и по ней.

**Why this priority**: редкий случай.

**Independent Test**: выбрать невыбранную ветку на плане после завершения и получить
продолжение урока по ней.

**Acceptance Scenarios**:

1. **Given** невыбранная ветка, **When** пользователь выбирает «Пройти и этот путь»,
   **Then** план перестраивается, урок продолжается по ней.

### Edge Cases

- Ветка из одного пути — это не развилка: карточка не показывается.
- Больше трёх путей: показываются три, учитель сужает выбор.
- Урок без плана (замер пропущен и план не построен): развилка показывается только
  карточкой.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Учитель MUST иметь способ предложить развилку из 2–3 путей с описанием.
- **FR-002**: Урок MUST ждать выбора пользователя, кроме явного «Выбери за меня».
- **FR-003**: План 052 MUST показывать ветки, выбранную и невыбранные.
- **FR-004**: Невыбранная ветка MUST оставаться доступной для прохождения позже.
- **FR-005**: Выбор MUST сохраняться в файле урока.
- **FR-006**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Развилка**: шаг плана, пути (название, описание, шаги), выбранный путь, кто выбрал.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Выбор пути — 1 действие.
- **SC-002**: 100% развилок без явного «Выбери за меня» ждут выбора пользователя.

## Assumptions

- Зависит от 051 и 052 (план и его проверки).
