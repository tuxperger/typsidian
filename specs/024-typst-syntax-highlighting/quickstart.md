# Quickstart: проверка подсветки Typst

Ссылки: [contracts/core-highlight-api.md](contracts/core-highlight-api.md),
[contracts/frontend-highlight.md](contracts/frontend-highlight.md), макет —
https://claude.ai/code/artifact/7c1a68f4-9a9c-4a5c-9aef-165fc970637f.

## §1. Ядро на обоих таргетах

```bash
.specify/scripts/typsidian/gates.sh core
```

Ожидается: `highlight_native` и `highlight_wasm` зелёные, таблица одна (FR-010, SC-001,
SC-004, SC-006).

## §2. Образец в web

1. `nix develop -c pnpm dev`. Открыть http://localhost:3000 с хранилищем браузера
   (`--opfs-vault`).
2. Создать заметку `Результаты.typ` и вставить текст артборда «Редактор» из макета.
3. Сценарий `scripts/dev/scenarios/syntax-highlight.mjs` снимает полотно:
   ```bash
   HL_CONTRAST=1 HL_PERF=1 nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
       scripts/dev/scenarios/syntax-highlight.mjs --opfs-vault --timeout 60000 --shot /tmp/024-editor.png
   ```
   Сценарий для каждого фрагмента образца проверяет класс `ts-syn-*` под ним и печатает
   расхождения. Консоль без исключений.
4. Сравнить снимок с артбордом: роли и начертания совпадают.

## §3. Набор и незакрытые пары (US3)

В той же заметке:
- набрать `#figure(` в строке 1. Строки ниже текущего абзаца не меняют классы;
- набрать `/*`. Остаток заметки — `ts-syn-comment`; закрыть `*/`, и раскраска совпадает с
  открытием заметки заново (FR-007);
- `Mod-/` на строке ставит `// ` (языковые данные перенесены).

## §4. Скорость (SC-002, SC-003)

Сценарий из §2 с `HL_PERF=1` (и `HL_CONTRAST=1` для SC-005): заметка на 5 000 строк из
повторённого образца, по 70 нажатий `#` в начале абзаца вверху, в середине и в конце.
Замер внутри страницы: от `beforeinput` до мутации DOM, после которой `#` стоит в
`.ts-syn-keyword` (порог 16 мс), рядом — то же для самого символа. Открытие — время от
текста до первой раскраски (порог 100 мс).

На desktop: собрать `nix develop -c pnpm --filter desktop tauri build --debug`, открыть ту же
заметку и набрать текст в середине. Визуально задержки нет, раскраска не мигает.

## §5. Темы и разделение (US4)

- Переключить тему в настройках при открытой заметке: раскраска та же, каретка на месте.
- Разделить редактор (014) с той же заметкой, править в левой половине: правая
  раскрашивается так же.

## §6. Не-Typst

В редакторе заметок открываются только заметки Typst: дерево не показывает другие файлы, а
`NoteEditor` получает подсветку по виду файла от ядра (`kind === "Note"`). Редактор
правил игнорирования (012) — отдельный компонент без расширения подсветки (FR-012).
