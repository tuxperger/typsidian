# Quickstart: Экспорт в HTML

1. Центр экспорта → формат HTML → отметить папку «Диссертация» (3 заметки) → Экспортировать.
2. `export/Диссертация/*.html` и `export/index.html`; ссылки `[[Методика]]` ведут на
   страницы, ссылка на заметку вне набора — серым с пометкой.
3. Заметка с `#rect(…)` — в итоге «выведено рисунком: rect», на странице SVG.
4. Страница открывается без сети: картинки встроены, внешних ресурсов нет.
5. На web — «Скачать архив».
6. Тесты: `cargo test --test html_export_native`, `wasm-pack test` (`html_export_wasm.rs`);
   бенч `html_export_scale`; сценарий `scripts/dev/scenarios/html-export.mjs`.
