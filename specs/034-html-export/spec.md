# Feature Specification: Экспорт в HTML

**Feature Branch**: `034-html-export`

**Created**: 2026-10-21

**Status**: Implemented

**Priority**: P3

**Summary**: Заметку или папку можно выгрузить веб-страницами: ссылки между заметками работают, картинки и доски на месте — готово к публикации на любом статическом хостинге.

**Input**: User description: "Экспорт в HTML: отдельная заметка или сайт из папки, с работающими ссылками между заметками."

## Clarifications

### Session 2026-10-23

Закрыто по конституции и существующим спекам, без вопроса пользователю.

- Q: Где запускается экспорт в HTML? → A: В Центре экспорта (009) — переключатель формата
  «PDF | HTML». Отмеченные заметки — это и есть сайт: одна заметка — страница, несколько —
  страницы и оглавление `index.html`; экспорт папки — отметить её группу. Ход, пропуск и
  отмена — те же, что у пакета PDF (принцип X).
- Q: Куда пишутся файлы? → A: В папку экспорта vault (009), структура папок заметок
  сохраняется: `export/Диссертация/Введение.html`, оглавление — `export/index.html`. На web
  после экспорта — кнопка «Скачать архив» (zip тех же файлов).
- Q: Что со ссылками `[[…]]`? → A: Ссылка на заметку, которая экспортирована вместе, ведёт
  на её страницу относительным адресом. Ссылка на заметку вне экспорта — текст подписи с
  пометкой «вне экспорта», не битая ссылка.
- Q: Что с вложениями? → A: Картинки и доски встраиваются в страницу, внешних ресурсов нет —
  страница открывается офлайн одним файлом.
- Q: Что значит «неподдерживаемое выводится изображением»? → A: Конструкцию, которую вывод
  HTML пропустил бы, страница показывает рисунком на её месте; в итоге экспорта строки
  названо, какие конструкции так выведены.
- Q: На каждой странице есть навигация? → A: Если страниц больше одной — ссылка «Оглавление»
  вверху страницы.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Заметка в HTML (Priority: P1)

«Экспорт → HTML» сохраняет заметку страницей с её вложениями рядом; страница открывается в
браузере без интернета.

**Acceptance Scenarios**:

1. **Given** заметка с формулами, картинками и доской, **When** она экспортирована в HTML,
   **Then** страница показывает всё содержимое, открывается офлайн.
2. **Given** конструкция, которую HTML-вывод не поддерживает, **Then** она выводится
   изображением, а не теряется, и об этом сказано в итоге экспорта.

---

### User Story 2 - Сайт из папки (Priority: P2)

Экспорт папки даёт набор страниц с оглавлением-навигацией; ссылки `[[…]]` между заметками
папки ведут на страницы, ссылки за пределы папки — помечены и не битые.

**Acceptance Scenarios**:

1. **Given** папка из 20 заметок, **When** экспортирована, **Then** 20 страниц и индекс;
   каждая внутренняя ссылка открывает нужную страницу.

### Edge Cases

- Папка экспорта — та же настройка, что у PDF (009).
- Ошибка сборки одной заметки не обрывает экспорт папки — она названа в итоге.
- Большая папка — ход и отмена (принцип X).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Заметку MUST можно экспортировать страницей HTML с вложениями.
- **FR-002**: Папку MUST можно экспортировать набором страниц с навигацией и работающими
  внутренними ссылками.
- **FR-003**: Неподдерживаемое HTML-выводом MUST выводиться изображением с упоминанием в итоге.
- **FR-004**: Экспорт MUST работать офлайн, без внешних ресурсов в результате.
- **FR-005**: Одинаково во всех оболочках; на web — скачиванием архива.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% внутренних ссылок экспортированной папки ведут на существующие страницы.
- **SC-002**: Экспорт папки из 100 заметок — не дольше 30 с на среднем ноутбуке.

## Assumptions

- Зависит от 009 (экспорт, папка экспорта), 005 (сборка), 002 (доски).
