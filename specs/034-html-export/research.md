# Research: Экспорт в HTML

## 1. Чем выводить HTML

**Decision**: `typst-html` 0.15.1 (та же версия, что весь Typst ядра): сборка с
`Feature::Html` даёт семантический HTML — заголовки, абзацы, списки, ссылки, формулы в
MathML, картинки встроены. Сборка — тот же цикл, что у предпросмотра и PDF
(`compile_collecting_failures`: резолв, шаблоны 007, выборки 020, встраивания 031); новый
вариант `Render::Html` меняет только последний шаг.
**Rationale**: один путь сборки (009 research §3); проба: заметка с формулой, списком и
ссылкой — корректный HTML, неподдерживаемое (`rect`) — предупреждение «X was ignored during
HTML export».
**Alternatives**: страницы SVG из предпросмотра в HTML-обёртке — текст не выделяется и не
индексируется; свой HTML-генератор по синтаксису — второй разбор Typst.

## 2. Неподдерживаемое — рисунком (FR-003)

**Decision**: из предупреждений сборки берутся имена пропущенных элементов; сборка
повторяется с правилом `#show selector(a).or(b): html.frame;` в начале первой строки (без
перевода строки — номера строк диагностик не сдвигаются), до двух повторов. `html.frame`
выводит элемент встроенным SVG. Имена попадают в итог: `ExportReport.as_images`.
Предупреждение «html export is under active development» не показывается.

## 3. Ссылки и сайт

**Decision**: перед сборкой `[[цель|подпись]]` переписывается: цель в наборе экспорта —
`#link("относительный/путь.html")[подпись]`, вне набора —
`#html.span(class: "ts-outside", title: "…")[подпись]`. Путь страницы — путь заметки с
`.html` в папке экспорта (как `pdf_path`). Набор > 1 — `index.html` со списком страниц по
папкам и ссылка «Оглавление» после `<body>` каждой страницы. Подписи («Оглавление», «вне
экспорта») приходят из переводов UI.

## 4. Пакет и архив

**Decision**: `BatchState.format` (`Pdf` по умолчанию, `Html`); цикл UI зовёт
`export_note_html` с набором путей пакета, по окончании — `export_site_index`. На web
`export_site_archive` собирает zip (без сжатия, CRC32 из `flate2`) из записанных файлов —
кнопка «Скачать архив». Запись страниц — `write_bytes`, атомарно (009 research §4).
