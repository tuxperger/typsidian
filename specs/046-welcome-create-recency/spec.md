# Feature Specification: Создание vault и давность недавних на стартовом экране

**Feature Branch**: `046-welcome-create-recency`

**Created**: 2026-11-01

**Status**: Draft

**Priority**: P3

**Summary**: На стартовом экране можно создать новый vault, а у недавних vault видно, когда их открывали.

**Input**: Поведение из макетов нового дизайна, отложенное фичей 044 (перевёрстка без нового поведения).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Новый vault и давность (Priority: P3)

Без открытого vault пользователь нажимает «Создать новый vault», выбирает место и имя —
открывается пустой vault. В списке «Недавние» у каждого vault — «сегодня», «вчера» или
дата последнего открытия.

**Independent Test**: создать vault со стартового экрана, закрыть, вернуться — он в
«Недавних» с пометкой «сегодня».

**Acceptance Scenarios**:

1. **Given** стартовый экран, **When** пользователь создаёт vault, **Then** папка
   создаётся и открывается как vault.
2. **Given** vault открывали вчера, **Then** в «Недавних» рядом с ним — «вчера».

### Edge Cases

- Папка с таким именем уже есть — создание не перезаписывает её, а сообщает об этом.
- Vault, открытый до этой фичи, давности не имеет — пометка не показывается.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Стартовый экран MUST давать «Создать новый vault» там, где оболочка умеет
  создавать папки.
- **FR-002**: Время последнего открытия MUST запоминаться для каждого известного vault.
- **FR-003**: «Недавние» MUST показывать давность открытия на языке интерфейса.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Новый vault создаётся и открывается не больше чем за три действия.

## Assumptions

- Макет — артборд 2 фичи 044. В 043 давность не показывалась: время открытия ядро не
  хранит.
- Зависит от 044.
