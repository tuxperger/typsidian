# Feature Specification: Найти похожий файл при ошибке сборки

**Feature Branch**: `048-build-error-similar-file`

**Created**: 2026-11-01

**Status**: Draft

**Priority**: P3

**Summary**: Если заметка не собирается из-за ненайденного файла, карточка ошибки предлагает похожие файлы vault и исправляет путь одним нажатием.

**Input**: Поведение из макетов нового дизайна, отложенное фичей 044 (перевёрстка без нового поведения).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Исправить путь (Priority: P3)

Сборка падает с «Файл не найден»; в карточке ошибки пользователь нажимает «Найти похожий
файл», видит файлы vault с близким именем и выбирает нужный — путь в тексте заменяется.

**Independent Test**: опечататься в пути `#import` — выбрать верный файл из списка,
заметка собирается.

**Acceptance Scenarios**:

1. **Given** ошибка «файл не найден», **Then** в карточке есть «Найти похожий файл».
2. **Given** список похожих, **When** пользователь выбирает файл, **Then** путь заменён
   одной правкой, которую отменяет «Отменить».

### Edge Cases

- Похожих файлов нет — список сообщает об этом, текст не меняется.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Для ошибки «файл не найден» карточка MUST предлагать «Найти похожий файл».
- **FR-002**: Список MUST содержать не больше 10 файлов vault, ближайших по имени.
- **FR-003**: Выбор MUST заменять путь в тексте заметки одной отменяемой правкой.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Опечатку в пути импорта можно исправить без ручного набора пути.

## Assumptions

- Макет — артборд 5 фичи 044; карточка ошибки — из 044.
- Зависит от 044.
