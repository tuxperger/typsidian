# Quickstart: проверка фичи Element Parameters

**Фича**: `008-element-parameters` | **Дата**: 2026-09-26

Сценарии проверки, а не инструкция по реализации. Функции — в
[contracts/element-params.md](./contracts/element-params.md), сущности — в
[data-model.md](./data-model.md).

## Предусловия

```bash
nix develop
```

## Автоматические проверки

Гейт принципов I и II — одна таблица, оба таргета:

```bash
cargo test -p typsidian-core --test elements_native
wasm-pack test --headless --chrome packages/core --test elements_wasm
cargo test -p typsidian-core elements::        # тесты схемы против Func::params()
```

Схема и Typst разошлись (новый параметр после обновления Typst) — тест схемы красный и
называет элемент и параметр. Черновик недостающих записей печатает генератор:

```bash
cargo run -p typsidian-core --example element-schema -- --check
```

Гейт принципа IV — после правки ядра обе пересборки:

```bash
pnpm build:wasm && pnpm -C ui build && pnpm typecheck
```

## Ручные сценарии

### 1. Вставка через форму (US1)

1. Открыть заметку, ⌘E → «Кодовый блок».
2. **Ожидание**: форма с полем «Язык»; «Будет вставлено» показывает ```` ``` ```` блок.
3. Выбрать `python` — «Будет вставлено» обновилось на первом же нажатии (FR-004).
4. Применить: в заметке ровно показанный текст (FR-005).
5. ⌘E → «Разрыв страницы» — вставляется сразу, без формы (FR-003).

### 2. Правка вставленного (US2)

1. Каретку внутрь `#columns(2, gutter: 8pt)[…]`.
2. Вызвать «Параметры» — кнопкой на панели вставки, правым кликом → «Параметры…»,
   из палитры ⌘K и сочетанием `Mod+Shift+E` (FR-006, все четыре).
3. **Ожидание**: форма заполнена `2` и `8pt`; фокус в первом поле (US4 AS1).
4. Применить без изменений — текст заметки не изменился символ в символ (FR-009).
5. Поменять число колонок на 3, применить — элемент переписан на месте (FR-008).
6. ⌘Z один раз — прежний текст (FR-010).

### 3. Непонятое не теряется (US3)

1. `#figure(image("a.png"), caption: [Подпись], foo: 1)` — «Параметры», поменять подпись,
   применить. **Ожидание**: `foo: 1` на месте (FR-012).
2. `#columns(n * 2)[…]` — поле «Число колонок» показывает `n * 2` как есть; поменять
   промежуток — `n * 2` не тронут (FR-012a).
3. `#image("a.png", width: 40%, width: 60%)` — «Параметры» недоступны, причина «параметр
   width указан дважды» названа во всех четырёх местах вызова (FR-011, FR-006).

### 4. Полный набор параметров (FR-012b, SC-001a)

1. «Параметры» у `#figure(…)`: сверху основные (содержимое, подпись, размещение,
   метка), блок «Все параметры» свёрнут.
2. У `#figure(…, gap: 1em)` блок раскрыт сам — задан не-основной параметр.

### 5. Вложенность (US5)

`#columns(2)[ #figure(image("a.png")) ]`: каретка в `image(…)` → параметры
изображения; в `#figure(` → рисунка; в тексте колонок → колонок (FR-016).

### 6. Запреты записи (FR-019, FR-020)

1. Vault только для чтения — «Применить» заперто, причина названа.
2. Открыть форму, в другом окне поменять текст элемента, вернуться, применить —
   расхождение названо, текст не перезаписан.

### 7. Паритет (FR-022)

Сценарии 1–3 на web и на desktop.

### 8. Длинная заметка (SC-005)

Заметка в 10 000 строк: быстрый набор и прокрутка каретки стрелками без задержек;
«Будет вставлено» обновляется в темпе набора.
