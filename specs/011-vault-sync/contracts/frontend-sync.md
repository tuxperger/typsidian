# Contract: интерфейс синхронизации (011)

Всё в `ui/src/sync/`; логики нет — только вызовы `SyncClient` и показ (принцип I). Тексты —
`ui/src/i18n/locales/*` под ключами `sync.*` (FR-039).

| Элемент | Где | Содержит | FR |
| --- | --- | --- | --- |
| Индикатор синхронизации | строка состояния | значок + краткое состояние (`актуально`, `N изменений`, `↑2 ↓1`, `Syncthing 40%`, `конфликты: 3`, `нет сети`); по клику — панель | FR-035, FR-019 |
| Панель «Синхронизация» | боковая панель (рядом с деревом) | разделы: История (изменения, снимок), Удалённый репозиторий, Syncthing, Конфликты, Хранитель | US1, US3–US5 |
| Мастер включения истории | диалог | шаг правил `.stignore` (если есть Syncthing) → шаг `.gitignore` → автор → первый снимок | FR-001, FR-028 |
| История файла | вкладка/панель у заметки, команда палитры `sync.file-history` | список снимков, сравнение, «вернуть эту версию» | FR-009…FR-011 |
| Разрешение конфликта | редактор слияния | 2 или 3 колонки (своя / их / общая), авто-совмещение с предпросмотром, кнопки выбора | FR-016, FR-025, FR-034 |
| Подключение удалённого | диалог | адрес, имя пользователя, токен (поле пароля; в web — предупреждение о хранилище браузера), посредник (только web) | FR-013, FR-014a, FR-037 |
| Настройки синхронизации | раздел «Vault» настроек (004) | автоснимки, пауза, автоотправка, автополучение, хранитель, Syncthing | FR-019, FR-029, FR-031 |

Команды палитры (`CommandId`): `sync.snapshot`, `sync.push`, `sync.pull`, `sync.file-history`,
`sync.open-panel`, `sync.resolve-conflicts`.

Недоступные действия (FR-036) рендерятся отключёнными с подсказкой из
`ShellCapabilities` — не скрываются.

Дерево: заметки с конфликтом получения или Syncthing помечаются значком; конфликтные
копии в дереве не показываются (FR-024).
