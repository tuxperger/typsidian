# Quickstart: Свернуть и развернуть папки разом

```bash
nix develop -c pnpm dev
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/tree-collapse.mjs --opfs-vault --shot /tmp/tree-collapse.png
```

Сценарий создаёт vault с папками на трёх уровнях и проверяет:

1. «Свернуть все папки» — видны только элементы верхнего уровня (US1 AS1, SC-003).
2. Раскрытие одной папки обычным нажатием — её подпапки свёрнуты (US1 AS3).
3. «Развернуть все папки» — видно всё дерево (US1 AS2).
4. Меню папки с подпапками: «Свернуть вложенные» и «Развернуть вложенные» меняют только ветку
   (US2 AS1–AS2); у папки без подпапок пунктов нет (US2 AS3).
5. Vault без папок — кнопки выключены (US1 AS4).
