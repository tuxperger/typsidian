# Контракт интерфейса дерева: свёртка разом

## Строка подписи «Vault»

| Элемент | Доступное имя (ru) | Состояние |
|---|---|---|
| Кнопка-значок | «Свернуть все папки» | выключена, если в дереве нет папок |
| Кнопка-значок | «Развернуть все папки» | выключена, если в дереве нет папок |

Подсказка (`title`) совпадает с доступным именем. Строка подписи не показывается в пустом
vault — как и сейчас.

## Меню папки

Только у папки с подпапками, после «Создать доску здесь», между разделителями:

1. «Развернуть вложенные»
2. «Свернуть вложенные»

## Действия состояния дерева

`setFoldersCollapsed(paths, collapse)` и `expandAll()` — рядом с существующими
`toggleExpanded`/`expand`; файлов не трогают. Пути даёт `folderPaths` из `buildTree.ts`: по
всему дереву — для «Свернуть все папки», по папке — для пунктов ветки.
