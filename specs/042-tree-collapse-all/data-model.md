# Data Model: Свернуть и развернуть папки разом

## Свёрнутость папок (состояние показа дерева)

- `collapsed: ReadonlySet<string>` — пути свёрнутых папок (уже есть, 001/023).
- Отсутствие пути — папка раскрыта; новая папка раскрыта.
- Переходы:
  - свернуть все → множество = пути всех папок дерева;
  - развернуть все → пустое множество;
  - свернуть ветку P → множество ∪ {P и все папки под P};
  - развернуть ветку P → множество ∖ {P и все папки под P};
  - переключить P (как прежде) → добавить/убрать только P.
- В файлы и настройки не пишется.
