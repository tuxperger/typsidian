# Feature Specification: Заметки в граф знаний

**Feature Branch**: `055-ai-notes-to-graph`

**Created**: 2026-11-02

**Status**: Implemented

**Priority**: P3

**Summary**: Можно выбрать заметки, папки или PDF из vault и добавить изложенное в них в граф знаний, чтобы уроки и практика опирались на то, что я уже записал.

**Input**: User description: "Notes import из LearnHarness: текстовые заметки и PDF превращаются в утверждения и цепочки графа тем же извлечением, что и уроки; источники организуются по папкам; повторный импорт обновляет вклад, а не плодит дубли."

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из принципа IX.

- Q: Можно ли импортировать весь vault одной кнопкой? → A: Нет. Принцип IX запрещает фоновую
  отправку всего vault: пользователь явно выбирает заметки или папки и видит их число и
  примерную стоимость до начала.
- Q: Импортируются ли файлы вне vault? → A: Нет, только внутри vault через проверку доступа
  050; чужой файл сначала кладут в vault (вложения 016).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Импортировать выбранные заметки (Priority: P1)

Пользователь выбирает в дереве заметки или папку и запускает «Добавить в граф знаний».
Перед началом видит, сколько файлов уйдёт модели и примерную стоимость, подтверждает.
Импорт идёт в фоне с прогрессом по файлам.

**Why this priority**: это и есть фича.

**Independent Test**: импортировать папку из трёх заметок и найти их утверждения в графе с
источниками-заметками.

**Acceptance Scenarios**:

1. **Given** выбрана папка, **When** пользователь запускает импорт, **Then** до отправки
   видит число файлов, объём и примерную стоимость и подтверждает.
2. **Given** импорт идёт, **When** файл обработан, **Then** его утверждения появляются в
   графе с источником-заметкой, прогресс обновляется.
3. **Given** импорт идёт, **When** пользователь отменяет, **Then** оставшиеся файлы не
   отправляются, уже добавленное остаётся (принцип X).
4. **Given** в папке есть запрещённая подпапка, **When** импорт запущен, **Then** её файлы
   пропускаются и перечислены в итоге как запрещённые.

---

### User Story 2 - Повторный импорт (Priority: P2)

Заметка изменилась; пользователь импортирует её снова. Вклад заметки в граф обновляется.

**Why this priority**: заметки живут, граф должен успевать за ними.

**Independent Test**: изменить заметку, импортировать повторно и не увидеть дублей.

**Acceptance Scenarios**:

1. **Given** заметка уже импортирована, **When** её импортируют снова, **Then** её вклад
   обновляется без дублей утверждений.
2. **Given** заметка переименована в приложении, **When** её импортируют, **Then** граф
   узнаёт прежний источник.

### Edge Cases

- PDF без текстового слоя: пропускается с причиной в итоге.
- Очень большой файл: делится на части; сбой части даёт итог «частично» с возможностью
  повтора.
- Файл не поддерживается (картинка, доска): пропускается с причиной.
- Нет сети посреди импорта: обработанное остаётся, итог показывает, что повторить.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Импорт MUST запускаться только явным выбором заметок, папок или PDF внутри
  vault; импорт всего vault одним действием MUST NOT предлагаться.
- **FR-002**: До отправки пользователь MUST видеть число файлов, объём, примерную стоимость
  (050 FR-014) и подтверждать.
- **FR-003**: Каждый файл MUST проходить проверку доступа 050; запрещённые MUST
  пропускаться и перечисляться в итоге.
- **FR-004**: Импорт MUST использовать то же извлечение и объединение, что и 054.
- **FR-005**: Импорт MUST идти в фоне с прогрессом по файлам и отменой; итог MUST
  показывать по каждому файлу: готово, частично, пропущен (с причиной), сбой.
- **FR-006**: Повторный импорт MUST обновлять вклад источника без дублей и узнавать
  источник после переименования в приложении.
- **FR-007**: Каждый запрос MUST попадать в журнал 050.
- **FR-008**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Импорт**: выбранные файлы, подтверждённая оценка, прогресс, итог по файлам.
- **Источник-заметка**: путь в vault, имя, связь с вкладом в граф (054).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% файлов из запрещённых папок не уходят модели.
- **SC-002**: Повторный импорт неизменённой заметки добавляет 0 дублей.
- **SC-003**: Во время импорта 50 заметок редактирование не прерывается ни разу.

## Assumptions

- Зависит от 054 (граф, извлечение), 050 (доступ, журнал), 016 (вложения для чужих файлов).
- Поддерживаемые виды файлов: заметки Typst, текстовые файлы и PDF с текстовым слоем.
