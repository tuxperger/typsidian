# Quickstart: импорт заметок

```bash
nix develop -c cargo test -p typsidian-core --test ai_native knowledge_import
```

Папка из двух заметок, PDF с текстом, PDF без текста, доски и заметки в запрещённой папке:
оценка перечисляет пропуски с причинами; импорт добавляет утверждения с источником-
заметкой; повтор неизменённого — 0 запросов и 0 дублей; изменённая заметка — только её
части; отмена посреди — оставшиеся не отправлены.

Браузер: `scripts/dev/scenarios/ai-knowledge-import.mjs`, сверка с артбордами A–D.
