# Quickstart: Поиск с заменой по vault

1. `nix develop -c pnpm dev`, открыть vault, `Mod+Shift+H`.
2. Ввести «Иванов», заменить на «Иванова»: каждое совпадение с «было → станет».
3. Снять два совпадения, «Заменить отмеченные» — изменены только отмеченные; итог называет
   заметки.
4. Открыть одну из заметок с правками до замены — правка пришла в редактор, несохранённое цело.
5. «Отменить замену» — тексты вернулись; заметка, поправленная после замены, названа.
6. Регулярное выражение с группой `(\w+)ов` → `$1ова`.
7. Сценарий: `nix develop -c node scripts/dev/browser.mjs http://localhost:3000 scripts/dev/scenarios/replace.mjs --opfs-vault`.
