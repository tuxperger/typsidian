**Summary**: Можно найти, в каком уроке учитель объяснял нужное или что я сам отвечал, и перейти прямо к этому месту — тем же локальным поиском, что и по заметкам.

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из принципа IX и
существующего поиска по vault.

- Q: Где искать? → A: В общем поиске vault появляется вид результатов «Уроки»; внутри урока
  — свой поиск по ленте. Индекс — локальный (принцип IX), ничего не уходит модели.
- Q: По чему ищется? → A: По тексту реплик учителя, вопросов, ответов и рассуждений, цели;
  без служебного содержимого файла.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Найти по всем урокам (Priority: P1)

Пользователь ищет «импульс» в общем поиске; среди результатов — уроки с фрагментами реплик.
Нажатие открывает урок на этом месте.

**Why this priority**: суть фичи.

**Independent Test**: найти слово из реплики учителя и попасть в урок на это событие.

**Acceptance Scenarios**:

1. **Given** слово есть в реплике учителя, **When** пользователь ищет его, **Then** урок
   есть в результатах с фрагментом и подсветкой.
2. **Given** результат выбран, **When** урок открывается, **Then** лента прокручена к
   событию, совпадение подсвечено.
3. **Given** слово встречается только в служебных данных файла урока, **When** идёт поиск,
   **Then** урока в результатах нет.

---

### User Story 2 - Найти внутри урока (Priority: P2)

В открытом уроке `Mod+F` ищет по ленте с переходом между совпадениями.

**Why this priority**: удобство длинных уроков.

**Independent Test**: найти слово в уроке из 50 шагов и перейти ко второму совпадению.

**Acceptance Scenarios**:

1. **Given** урок открыт, **When** пользователь ищет слово, **Then** видит число
   совпадений и переходит между ними.

### Edge Cases

- Урок изменился синхронизацией: индекс обновляется, как у заметок.
- Урок в запрещённой для агента папке: ищется как обычно — поиск локальный и модели ничего
  не передаёт.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Общий поиск vault MUST находить уроки по тексту реплик, вопросов, ответов,
  рассуждений и цели.
- **FR-002**: Служебные данные файла урока MUST NOT попадать в результаты.
- **FR-003**: Переход из результата MUST открывать урок на найденном событии.
- **FR-004**: Внутри урока MUST быть поиск с переходом между совпадениями.
- **FR-005**: Индекс MUST строиться и храниться локально; поиск MUST NOT обращаться к
  моделям.
- **FR-006**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Совпадение в уроке**: урок, номер события, фрагмент, позиции.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Поиск по 200 урокам возвращает результаты менее чем за 1 секунду.
- **SC-002**: 0 запросов к моделям при поиске.

## Assumptions

- Зависит от 051 и существующего поиска по vault.
