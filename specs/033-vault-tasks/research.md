# Research: Задачи из заметок

## 1. Запись задачи и срока

**Decision**: строка пункта списка `-`/`+` с отметкой `[ ]` или `[x]`/`[X]` после маркера:
`^(\s*)([-+]) \[( |x|X)\] (.*)$`. Пункт засчитывается, только если по разбору Typst строка —
`ListItem`/`EnumItem` разметки (не код, не сырой текст, не комментарий): лист в начале строки
— маркер списка. Срок — первая дата `ГГГГ-ММ-ДД` после `📅`, `срок:` или `due:`; в показанном
тексте этот кусок убран. Вложенность — по отступу: родитель — ближайшая выше задача с меньшим
отступом.
**Rationale**: валидный Typst без библиотеки (принцип VI) и знакомая запись Markdown/Obsidian.

## 2. Индекс задач

**Decision**: производный файл устройства `.typsidian/tasks.json` (в `derived_paths`, как
кэш): по заметке — отпечаток файла (`FileStamp` из списка vault) и её задачи. `tasks_view`
берёт список заметок vault, перечитывает только заметки с другим отпечатком или новые,
выкидывает удалённые и пишет файл, если что-то поменялось.
**Rationale**: FR-006 «из индекса» без новой схемы в кэше SQLite и одинаково на native и web
(принцип II); первый показ читает все заметки, последующие — только изменённые (SC-001).
**Alternatives**: колонка задач в `cache.sqlite` — две реализации (native SQLite, web свой
кэш) и миграция схемы; чтение всех заметок на каждый показ — секунды на web.

## 3. Фильтры

**Decision**: в ядре: состояние, срок (просрочено/сегодня/неделя/без срока относительно
`today` из часов границы), папка (префикс пути), условия свойств — `properties::query::matches_all`
над `indexed_notes` (020) с `FilterMode::And`; строка условий разбирается
`search::parse_conditions`. Группировка — по заметке или по сроку (просрочено, сегодня,
неделя, позже, без срока).

## 4. Отметка

**Decision**: `task_toggle(backend, request, editor_text)` по образцу `links::fix_links`
(028): запрос — путь, номер строки и её текст. Строка ищется по тексту: сначала на прежнем
номере, иначе ближайшая с тем же текстом; нет — `Stale`. Меняется один знак `[ ]`↔`[x]`.
Открытая заметка — ответ `EditorEdit` (одна правка редактора, Ctrl+Z), закрытая — запись со
сверкой отпечатка (`Conflict` → `Stale`). SC-002.

## 5. Команда редактора

**Decision**: `task_toggle_at(text, offset) -> Option<TextEdit>`: строка под кареткой —
задача → переключить; пункт списка без отметки → вставить `[ ] `; иначе `None`.

## 6. Отличие от макета T1

**Decision**: после отметки список сразу перечитывается по текущему фильтру — отмеченная
задача при фильтре «невыполненные» уходит из списка, а не остаётся зачёркнутой до закрытия
окна, как в примечании к макету. Снять отметку можно фильтром «все» или Ctrl+Z в открытой
заметке.
**Rationale**: список — всегда ответ ядра на фильтр (принцип I); «остающиеся» строки
потребовали бы второго списка в UI поверх ответа ядра.
