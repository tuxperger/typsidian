# Quickstart: Задачи из заметок

1. Три заметки, 10 задач `- [ ] …`, одна — в блоке кода, две — вложенные, у трёх срок.
2. Палитра → «Задачи»: 10 задач по заметкам, вложенные — с отступом, задачи из кода нет.
3. Отметить задачу в закрытой заметке — в файле поменялась одна строка; в открытой —
   правка в редакторе, Ctrl+Z снимает.
4. Щелчок — заметка на строке задачи. Фильтры: просрочено, сегодня, папка, `тег:глава`.
5. Палитра «Переключить задачу» на строке `- пункт` → `- [ ] пункт` → `- [x] пункт`.
6. Тесты: `cargo test --test tasks_native`, `wasm-pack test` (`tasks_wasm.rs`); бенч
   `tasks_scale`; сценарий `scripts/dev/scenarios/tasks.mjs`.
