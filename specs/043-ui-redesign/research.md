# Research: Оболочка интерфейса по дизайну Typsidian.pdf

## Decision 1 — эталон дизайна

- **Decision**: Эталон — Typsidian.pdf (4 экрана). Холст Claude Design не читается: чтение
  артефакта отдаёт только оболочку редактора, `DesignSync` видит лишь проекты Claude Design,
  а холст-артефакт к ним не относится.
- **Rationale**: PDF — дизайн пользователя этого же направления; расхождения с холстом
  поправимы по его выгрузке.

## Decision 2 — плашка режима ввода и давность vault не рисуются

- **Decision**: «NORMAL» в строке состояния и «сегодня / вчера» в недавних vault не
  показываются.
- **Rationale**: режима Vim нет (026), время открытия vault ядро не хранит. Элемент без
  поведения вводит в заблуждение; добавлять данные в ядро ради подписи — вне объёма.

## Decision 3 — вид «Текст / Рядом / Документ» — поле раскладки устройства

- **Decision**: Вид хранится рядом с шириной дерева и долей колонок (`usePaneLayout`).
- **Rationale**: это свойство раскладки окна, как ширина колонок, и на другом устройстве
  может отличаться. В vault не пишется.

## Decision 4 — убранные из шапки действия

- **Decision**: Граф, оглавление, источники, настройки — значки внизу дерева; остальное — уже
  существующие команды палитры с прежними сочетаниями. Сворачивание дерева — команда палитры
  и прежнее сочетание.
