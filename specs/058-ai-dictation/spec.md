# Feature Specification: Диктовка ответов в уроке

**Feature Branch**: `058-ai-dictation`

**Created**: 2026-11-02

**Status**: Draft

**Priority**: P3

**Summary**: Ответ и рассуждение «думаю вслух» можно надиктовать голосом, а не печатать; распознаёт речь подключённый провайдер или модель на моём устройстве.

**Input**: User description: "Dictation из LearnHarness: поля рассуждения можно заполнять голосом; распознавание речи многоязычное."

## Clarifications

### Session 2026-11-02

Вопросы закрыты без обращения к пользователю: ответы следуют из принципа IX и решений 050.

- Q: Какой сервис распознаёт речь? → A: Подключение распознавания, которое настраивает сам
  пользователь, по образцу 050: OpenAI по ключу или свой совместимый адрес, в том числе
  локальный сервер распознавания. Отдельные сторонние сервисы вне этой схемы требуют
  MAJOR-поправки конституции и в фичу не входят.
- Q: Хранится ли запись голоса? → A: Нет. Сохраняется только распознанный текст в поле
  ответа; звук после распознавания удаляется.
- Q: Попадает ли диктовка в журнал отправленного? → A: Да, как запрос без звука: время,
  подключение, длительность записи, распознанный текст.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Надиктовать рассуждение (Priority: P1)

В поле ответа или «думаю вслух» пользователь нажимает микрофон, говорит и останавливает
запись. Распознанный текст появляется в поле, его можно поправить до отправки.

**Why this priority**: это и есть фича.

**Independent Test**: подключить локальный сервер распознавания, надиктовать фразу и
увидеть её в поле.

**Acceptance Scenarios**:

1. **Given** распознавание подключено, **When** пользователь записывает и останавливает,
   **Then** текст вставляется в поле на место курсора и не отправляется сам.
2. **Given** приложению не дан доступ к микрофону, **When** пользователь нажимает микрофон,
   **Then** видит, как дать доступ в этой оболочке.
3. **Given** распознавание не подключено, **When** пользователь ищет микрофон, **Then**
   кнопки нет или она ведёт в настройки подключения.
4. **Given** идёт запись, **When** пользователь отменяет, **Then** ничего не отправляется.

---

### User Story 2 - Язык распознавания (Priority: P2)

Пользователь выбирает язык распознавания или автоопределение для смешанной речи.

**Why this priority**: рассуждения часто смешивают языки и термины.

**Independent Test**: выбрать автоопределение и надиктовать фразу на двух языках.

**Acceptance Scenarios**:

1. **Given** выбран язык, **When** идёт распознавание, **Then** используется он.
2. **Given** выбрано автоопределение, **When** речь смешанная, **Then** текст распознаётся
   без принудительного перевода на один язык.

### Edge Cases

- Сеть оборвалась после записи: запись держится до повтора или отмены, но не дольше сессии
  приложения, и не сохраняется на диск.
- Запись слишком длинная: останавливается по пределу с предупреждением заранее.
- Провайдер отверг ключ: сообщение из таблицы отказов 050.
- Серверный режим: звук идёт на сервер пользователя, оттуда — к подключению распознавания;
  на сервере не сохраняется.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Диктовка MUST быть доступна в полях ответа и рассуждения уроков (051) и
  практики (053).
- **FR-002**: Распознавание MUST идти только через подключение, настроенное пользователем
  (OpenAI по ключу или свой совместимый адрес), с хранением ключа по правилам 050 FR-007.
- **FR-003**: Распознанный текст MUST вставляться в поле для правки и MUST NOT
  отправляться учителю автоматически.
- **FR-004**: Звук MUST NOT сохраняться на диск ни на устройстве, ни на сервере.
- **FR-005**: Каждое распознавание MUST попадать в журнал 050 без звука: время,
  подключение, длительность, текст.
- **FR-006**: Пользователь MUST выбирать язык или автоопределение.
- **FR-007**: Запись MUST иметь предел длительности, отмену и видимый индикатор.
- **FR-008**: Все тексты интерфейса MUST быть локализованы.

### Key Entities

- **Подключение распознавания**: вид, адрес, модель, язык; ключ — секрет устройства.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: После остановки записи 30-секундной фразы текст появляется в поле не дольше
  чем за время ответа подключения плюс 1 секунда.
- **SC-002**: Поиск звуковых файлов в vault и служебных каталогах после диктовки даёт 0
  результатов.
- **SC-003**: 100% распознаваний есть в журнале 050.

## Assumptions

- Зависит от 051, 050 (подключения, ключи, журнал), 053 — по мере готовности.
- Доступ к микрофону на рабочем столе и Android требует разрешений оболочки
  (`tauri-shell-agent`).
