# Feature Specification: Открыть заметку рядом из палитры

**Feature Branch**: `049-palette-open-beside`

**Created**: 2026-11-01

**Status**: Draft

**Priority**: P3

**Summary**: Из палитры команд заметку можно открыть не в текущей вкладке, а в соседней группе редактора.

**Input**: Поведение из макетов нового дизайна, отложенное фичей 044 (перевёрстка без нового поведения).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Открыть рядом (Priority: P3)

В палитре пользователь выбирает заметку и нажимает сочетание «открыть рядом» — заметка
открывается в соседней группе редактора (014), текущая остаётся на месте.

**Independent Test**: открыть заметку А, в палитре выбрать Б «рядом» — видны обе.

**Acceptance Scenarios**:

1. **Given** палитра с заметкой, **When** пользователь выбирает «открыть рядом», **Then**
   заметка открывается в соседней группе; если её нет — группа создаётся.

### Edge Cases

- На телефоне соседних групп нет — действие не предлагается.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Палитра MUST давать «открыть рядом» для заметок и показывать его в строке
  подсказок.
- **FR-002**: Сочетание MUST сверяться с занятыми; занятое не используется.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Заметка открывается рядом не больше чем двумя действиями из палитры.

## Assumptions

- Макет — артборд 3 фичи 044 («Ctrl Enter открыть рядом»).
- Зависит от 044 и 014.
