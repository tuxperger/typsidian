# Контракт: получение и установка внешнего шаблона

**Фича**: `007-template-download` | **Модуль**: `packages/core/src/preview/packages.rs`

## Форма

```rust
/// Откуда брать архив (FR-003, FR-004).
pub enum TemplateSource {
    /// Общий реестр: адрес выводится из спецификации пакета.
    Registry,
    /// Адрес, указанный пользователем для этого шаблона.
    Url(String),
}

/// Адрес, к которому приложение обратится. Чистая функция — её результат
/// показывается пользователю до и после попытки (FR-006, FR-007).
pub fn source_url(spec: &PackageSpec, source: &TemplateSource) -> Option<String>;

/// Разбор архива **целиком в памяти**, с проверкой каждой записи.
/// Ни одного обращения к файловой системе (FR-019, FR-020).
pub fn unpack(archive: &[u8]) -> Result<Vec<(String, Vec<u8>)>, InstallError>;

/// Отпечаток установленного содержимого (FR-022, FR-024).
pub fn fingerprint(files: &[(String, Vec<u8>)]) -> String;

/// Запись разобранного шаблона в vault. Манифест — последним (research §5).
pub async fn install<B: VaultBackend>(
    backend: &mut B,
    spec: &PackageSpec,
    files: &[(String, Vec<u8>)],
) -> Result<String, InstallError>;

/// Сетевой вызов — тонкая оболочка; в тестах не участвует.
pub async fn fetch(url: &str, timeout: Duration) -> Result<Vec<u8>, InstallError>;
```

## Обязательства

1. **`unpack` и `fingerprint` — чистые.** Ни сети, ни файлов. Отсюда вся таблица проверок
   гоняется одинаково на обоих таргетах, без сети и без диска.
2. **Ни одного файла до полной проверки.** `install` принимает уже разобранный и проверенный
   набор; создать частично проверенный шаблон структурно невозможно.
3. **Манифест последним.** Признак «установлен» у фичи 006 — наличие `typst.toml`. Пока его
   нет, установка для остальной системы не состоялась (FR-020).
4. **Никаких `cfg` по таргету.** Различие платформ скрыто внутри `reqwest`, а не в этом модуле.

## Различимые причины отказа (FR-008 спеки: общих «не удалось» нет)

| Причина | Когда |
|---------|-------|
| `Offline` | сети нет |
| `SourceUnavailable { url }` | источник ответил отказом |
| `Blocked { url }` | среда клиента не дала обратиться (FR-015) |
| `VersionNotFound { spec }` | источник ответил «нет такой версии» (FR-017) |
| `TimedOut { url }` | предел ожидания исчерпан (FR-014) |
| `ArchiveRejected { reason }` | запись ведёт за пределы папки версии либо архив не разбирается (FR-019) |
| `NotWritable` | папка заметок недоступна на запись (FR-018) |
| `AutoDownloadDisabled { spec }` | автозагрузка выключена (FR-009) |

## Проверяемые сценарии

| Сценарий | Ожидание |
|----------|----------|
| Архив с `lib.typ` и `typst.toml` | оба файла установлены, отпечаток посчитан |
| Запись с `../` в пути | `ArchiveRejected`, **ни одного** файла не создано |
| Запись с абсолютным путём | `ArchiveRejected` |
| Архив не разбирается | `ArchiveRejected` |
| Архив с общей обёрткой-папкой | обёртка срезана, `lib.typ` лежит в корне версии |
| Тот же набор файлов в другом порядке | тот же отпечаток |
| Файлы отличаются на один байт | отпечаток отличается |
| `("ab","c")` против `("a","bc")` | отпечатки различны — длина участвует в хэше |
| Пространство имён не `preview`, источник `Registry` | `source_url` возвращает `None`: в сеть идти некуда (FR-005) |
| Vault только на чтение | `NotWritable`, ни одного файла |
