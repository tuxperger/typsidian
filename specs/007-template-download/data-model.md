# Data Model: Template Download

**Фича**: `007-template-download` | **Дата**: 2026-09-25

Сущности фичи и их форма в коде. Поведение — в [spec.md](./spec.md), форма функций — в
[contracts/template-install.md](./contracts/template-install.md). Файл дописан задним числом
по фактическому коду (tasks.md T047): расхождение между ним и кодом — дефект этого файла.

## Раскладка на диске

Всё, что фича пишет, лежит в служебном месте папки заметок (фича 006). Заметки и файлы
пользователя вне `.typsidian/` не трогаются ни одной операцией.

```text
<vault>/.typsidian/
├── vault.json                          # настройки уровня vault; секция "templates"
└── packages/
    ├── installed.json                  # реестр установленного (для перечня в UI)
    └── <namespace>/<name>/<version>/   # папка версии — раскладка 006
        ├── lib.typ, …                  # файлы шаблона как в архиве, без обёртки
        ├── .typsidian-fingerprint      # отпечаток + состав установленного
        └── typst.toml                  # манифест — пишется последним
```

## Источник — `TemplateSource`

`packages/core/src/preview/packages.rs`. Откуда брать архив (FR-003, FR-004).

| Вариант | Адрес | Когда |
|---------|-------|-------|
| `Registry` | `https://packages.typst.org/<ns>/<name>-<x.y.z>.tar.gz` | пространство `preview` и нет своего адреса |
| `Url { url }` | заданный пользователем | для шаблона есть запись в `template_sources` |

Для `Registry` вне пространства `preview` адреса нет (`source_url` → `None`): в сеть за таким
шаблоном идти некуда, и сборка **не** порождает сообщений о загрузке (FR-005, US1 AS4).

## Политика — `TemplatePolicy`

`packages/core/src/preview/compile.rs`. Собирается из настроек уровня vault методом
`VaultOverrides::template_policy()`; UI её не собирает (принцип I).

| Поле | Тип | Откуда | Умолчание |
|------|-----|--------|-----------|
| `auto_download` | `bool` | `templates.auto_download` | `true` (Assumptions спеки) |
| `sources` | `Vec<(spec, url)>` | `templates.sources` | пусто |

В `.typsidian/vault.json`:

```json
{
  "templates": {
    "auto_download": false,
    "sources": { "@preview/codly:1.3.0": "https://example.org/codly.tar.gz" }
  }
}
```

**Инвариант записи**: пара `spec → url` пишется, только если `spec` разбирается как
`@ns/name:x.y.z`, а `url` — `http(s)://` с хостом и без пробелов
(`is_valid_template_source`). Негодная пара отклоняет запись целиком с
`VaultSettingsError::InvalidTemplateSource { spec }`; файл не меняется.

## Отчёт об установке — `InstallReport`

Успешная попытка (FR-006). Попадает в диагностику сборки и в ответ явной установки.

| Поле | Смысл |
|------|-------|
| `spec` | `@preview/codly:1.3.0` — строкой, как в заметке |
| `url` | полный адрес, с которого получен архив |
| `fingerprint` | отпечаток установленного (hex BLAKE3, 64 знака) |
| `file_count` | число установленных файлов |

## Исход попытки — `InstallError`

Каждая причина отдельна (FR-007, SC-008). Сериализуется размеченным объединением
`{ "kind": …, … }` — одинаково с web и из команды Tauri.

| `kind` | Поля | Когда |
|--------|------|-------|
| `Offline` | `url` | соединение не установлено (только native: браузер это не различает) |
| `SourceUnavailable` | `url` | источник ответил не-успехом, кроме 404 |
| `Blocked` | `url` | среда клиента не дала обратиться; текст подсказывает положить шаблон руками (FR-015) |
| `VersionNotFound` | `spec` | источник ответил 404 (FR-017) |
| `TimedOut` | `url` | исчерпан предел `FETCH_TIMEOUT` = 30 с (FR-014) |
| `ArchiveRejected` | `reason` | архив не разбирается, больше предела, без манифеста или с путём наружу (FR-019) |
| `NotWritable` | — | vault только для чтения (FR-018) |
| `AutoDownloadDisabled` | `spec` | автозагрузка выключена; попытки не было (FR-009) |

## Отпечаток

`fingerprint(files)` — BLAKE3 по файлам, отсортированным по пути; для каждого: путь, `\0`,
длина (u64 LE), содержимое. Файл отпечатка в хэш не входит.

- порядок записей в архиве не влияет (FR-024);
- длина участвует — `("ab","c")` и `("a","bc")` различимы;
- считается по **установленным** файлам, не по архиву.

`.typsidian-fingerprint` — первая строка отпечаток, далее по строке на установленный файл.
Состав нужен сверке: обхода каталога у `VaultBackend` нет. Файл без состава (прежний
формат) даёт `FingerprintCheck::Unknown`.

## Сверка — `FingerprintCheck`

| Вариант | Смысл |
|---------|-------|
| `Matches` | содержимое совпадает с записанным |
| `Diverged { recorded, actual }` | файл изменён или исчез; сборка пишет предупреждение, ничего не переустанавливая (FR-023) |
| `Unknown` | шаблон положен руками — сверять не с чем; **не** приравнивается к «совпадает» |

Сверка идёт по шаблонам, которые документ действительно читал, раз за сеанс (`PackageCache::
mark_verified`). Явная установка снимает отметку (`forget_verified`).

## Установленный шаблон — `InstalledTemplate`

Строка перечня в настройках (US5 AS1), хранится в `packages/installed.json`.

| Поле | Смысл |
|------|-------|
| `spec`, `url`, `fingerprint`, `file_count` | как в `InstallReport`; `url` пуст — установлен не приложением |

Реестр — список, а не истина: перед выдачей каждая запись проверяется наличием манифеста,
и удалённый руками шаблон из перечня исчезает. Отказ записи реестра установку не отменяет.

## Замечание с шаблоном — `Diagnostic.template`

`packages/core/src/preview/diagnostics.rs`. Необязательное поле: спецификация шаблона, который
можно загрузить явно. Ставится только у замечаний о **неудавшейся или не начатой** загрузке
шаблона с источником. По нему UI показывает кнопку «Загрузить шаблон» (FR-010) — без разбора
текста сообщения.

## Переходы установки

```text
не установлен ──(сборка, auto_download, есть источник)──► fetch → unpack → install
      │                                                        │          │       │
      │                                              отказ сети│  архив отклонён  │NotWritable
      │                                                        ▼          ▼       ▼
      │                                                    не установлен (ни одного файла)
      │
      └──(auto_download выключен)──► AutoDownloadDisabled ──(кнопка)──► fetch → …

install: файлы → .typsidian-fingerprint → typst.toml   (манифест последним = «установлен», FR-020)
установлен ──(правка файла руками)──► Diverged (предупреждение, без переустановки)
```
