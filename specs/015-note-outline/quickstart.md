# Quickstart: проверка оглавления заметки

Все команды — из корня репозитория внутри `nix develop` (cargo-команды строго по одной, без
таймаутов). Если wasm-тесты падают с «http status: 404» — запускать через
`env -u LD_LIBRARY_PATH`.

## Ядро

```sh
nix develop --command cargo test -p typsidian-core --lib structure
nix develop --command cargo test -p typsidian-core --test structure_native
nix develop --command cargo build -p typsidian-core --target wasm32-unknown-unknown
nix develop --command bash -c "cd packages/core && wasm-pack test --headless --chrome -- --test structure_wasm"
nix develop --command cargo bench -p typsidian-core --bench structure_scale
```

Что доказывают тесты (`structure_cases`, оба таргета):
- разбор: заголовки знаками `=` и вызовом `heading`, уровни не подряд; `=` в блоке кода,
  комментарии и строке заголовком не считается; заголовки в цикле, замыкании и `#include` не
  показаны (FR-002, Edge Cases);
- читаемый текст: оформление, ссылка, формула, пустой остаток → начало исходной записи
  (FR-001);
- рисунки и таблицы с подписью, без подписи; метка при заголовке и рисунке против отдельной;
  `<ключ>` в `#cite(<ключ>)` — не определение; ссылки `@имя` с местами;
- места: строка и колонка с единицы, границы в UTF-16 на тексте с кириллицей и символами вне
  BMP;
- вид: свёрнутость, фильтр с родителями без учёта регистра, счётчики, пустые состояния;
- текущий раздел: выше первого заголовка, на границе, в свёрнутой ветке (FR-007, US3 AS3);
- перенос свёрнутости через правку внутри раздела, переименование, вставку заголовка;
- поиск заголовка в текстовом слое на документе, собранном настоящим компилятором.

Бенчмарк `structure_scale` печатает время `outline`, `outline_view`, `outline_active` на
заметке в 10 000 строк с 2 000 заголовков; бюджеты — research.md §9.

## В работающем приложении (web)

```sh
nix develop -c pnpm dev          # в фоне, :3000
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/outline.mjs --opfs-vault --shot <scratchpad>/outline.png
```

Сценарий создаёт заметку с заголовками трёх уровней, рисунком с подписью и меткой, открывает
оглавление сочетанием `Ctrl+Shift+O` и печатает: текст колонки, строку с `aria-current` после
перемещения каретки, положение каретки после клика по последнему пункту, замеры (время до
появления оглавления заметки в 10 000 строк; время `noteOutline` и `noteOutlineActive` при
2 000 заголовков; задержку обработки нажатия с колонкой и без неё). Снимок сверяется с
макетом `Typsidian Оглавление.dc.html`, 1a–1c.

## Ручная проверка

1. **US1.** Открыть заметку с заголовками трёх уровней → `Ctrl+Shift+O`: колонка «Структура»
   повторяет порядок и вложенность, текст без разметки. Клик по последнему пункту: каретка в
   начале заголовка, он виден, фокус в редакторе; предпросмотр показывает тот же раздел.
2. Внести ошибку сборки (незакрытая скобка ниже по тексту): оглавление не меняется и не
   пустеет.
3. Заметка без заголовков: пояснение вместо списка. Открыть доску: «У доски нет оглавления».
4. **US2.** Дописать `== Новый раздел`: появляется в колонке не позже полсекунды после
   остановки набора, без сохранения. Сменить `==` на `===`: отступ меняется. Каретку — в
   середину третьего раздела: подсвечен третий пункт и виден в колонке; выше первого
   заголовка — подсветки нет. Перейти к другой заметке: оглавление её.
5. **US3.** Свернуть первый раздел: подзаголовки скрыты; дописать текст в заметку —
   свёрнутость на месте; каретку внутрь свёрнутого подраздела — подсвечен свёрнутый
   родитель. В фильтр — «введ»: остались пункты со словом «Введение» и их родители
   (приглушены).
6. **US4.** Меню видов → «Рисунки и таблицы», «Метки»: под разделами появились пункты
   рисунков с подписью и метка `<итог>`; метка сразу за заголовком показана при нём.
   Перезапустить приложение: выбор сохранился. Выключить: только заголовки.
7. **Клавиатура.** Tab в колонку → стрелки, ←/→ сворачивают и разворачивают, Enter
   переходит, Esc возвращает в редактор. Палитра `Ctrl+K` → «Оглавление».
8. **Узкое окно.** Сузить окно до ~900px: колонка уходит; `Ctrl+Shift+O` открывает боковую
   шторку с фокусом в фильтре; переход закрывает её.
9. **Телефон (Android).** Оглавление открывается отдельным действием шторкой снизу и
   закрывается после перехода.

## Что этим не проверяется

- **iOS** — оболочки нет; не проверено и не будет проверено в рамках фичи.
- **Desktop-оболочка в headless-режиме** — `tauri-driver` в окружении нет; desktop
  проверяется вручную по шагам 1–8.
