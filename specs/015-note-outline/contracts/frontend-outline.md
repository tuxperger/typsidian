Колонку заметки `ui/src/note-panel/` и её шторку снизу для телефона заводит 013. Здесь —
только то, что добавляет 015. Имена компонента колонки, хука её состояния и места хранения
сверяются с реализованной 013 первой задачей (tasks.md, Foundational).

## Клиенты

```ts
outline(text: string): Promise<Outline>;

```


## useOutline (`ui/src/note-panel/useOutline.ts`)

Вход: клиент, путь открытой заметки, текст редактора, каретка (UTF-16), `OutlineKinds`,
включён ли режим. Выход: `OutlineView | null`, ключ подсвеченной строки, действия `toggle`,
`setFilter`, `collapseAll`/`expandAll`.

Хук выбирает **момент** вызова и больше ничего (research.md §9):

```text
заметка сменилась        → outline(text) сразу; collapsed/filter — из памяти по пути заметки
текст изменился          → через 250 мс тишины: next = outline(text)
                           collapsed = outlineCarry(prev, next, collapsed)
                           view = outlineView(next, request)
каретка сдвинулась       → не чаще раза в 100 мс: active = outlineActive(outline, request)
toggle / filter / kinds  → view = outlineView(outline, request) сразу
```

- Ответ на устаревший текст или заметку отбрасывается (номер версии, как в
  `useElementAtCaret`).
- Режим выключен или колонка скрыта → ни одного вызова ядра (SC-004 меряется и для этого
  случая).
- Хук не ищет заголовки, не фильтрует, не решает, какая строка активна, и не сравнивает
  места с кареткой: `collapsed` — набор непрозрачных ключей, `filter` — строка (принцип I).

## OutlineMode (`ui/src/note-panel/OutlineMode.tsx`)

Режим «Структура» колонки. Макет — `Typsidian Оглавление.dc.html`, 1a и 1c; расхождения —
research.md §13–§19.

- **Шапка колонки** (013): в переключатель добавлен «Структура»; справа метка-счётчик из
  `view.counts` и кнопка-меню видов: «Рисунки и таблицы», «Метки» (отмечаемые,
  `ContextMenu`).
- **Поле фильтра** — под шапкой; `Esc` очищает непустое поле, на пустом — возвращает фокус в
  редактор.
- **Дерево**: `role="tree"`, строки `role="treeitem"` с `aria-level`, `aria-expanded` (у
  строк с вложенными), `aria-current="true"` у подсвеченной. Одна строка в порядке обхода
  Tab (roving tabindex).
- **Строка заголовка** — 11.5px sans, отступ по `level` (уровень 2 — 26px, уровень 3 — 40px,
  дальше +14px), шеврон у строк с `has_children`; длинный текст обрезается многоточием,
  полный — в `title` и по удержанию на сенсорном экране. `text_is_source` — моноширинным.
- **Подсвеченная строка**: фон steel-900, текст steel-100, оранжевая линия слева 2px;
  прокручивается в видимую область колонки (`scrollIntoView({ block: "nearest" })`), когда
  подсветка сменилась (FR-007).
- **Строки рисунка, таблицы, метки** — моноширинные, с приставкой из переводов («рис.»,
  «табл.») и `<метка>`; номеров нет.
- **Совпадение фильтра** — куски `segments` с `highlighted` на фоне
  `rgba(255,106,0,.35)`; `dimmed` — `opacity: .45`.
- **Пустые состояния** (FR-012), текст из переводов:
  - `NoHeadings` — «В заметке нет заголовков. Начните строку с =, и они появятся здесь.»;
  - `NoMatches` — «Ничего не найдено»;
  - открыта доска — «У доски нет оглавления»;
  - заметка не открылась из-за предела размера (`ReadError::TooLarge`) — «Заметка слишком
    велика — оглавление не строится»;
  - заметка не открыта — состояние колонки 013.
- Все правила CSS — с префиксом `.ts-outline*` (селекторы без `.ts-*` залетают в Excalidraw).

### Клавиатура (FR-014)

| Клавиша | В дереве |
|---|---|
| ↑ / ↓ | предыдущая / следующая строка |
| ← | свернуть строку с вложенными; иначе — к родителю (`row.parent`) |
| → | развернуть свёрнутую; иначе — к первой вложенной |
| Home / End | первая / последняя строка |
| Enter, пробел | перейти к пункту |
| Esc | фокус в редактор; в шторке — закрыть |

В поле фильтра ↓ переводит фокус на первую строку дерева, Enter — переход к первой
подходящей (не `dimmed`) строке.

## Переход к пункту (FR-003, FR-004, SC-002)

`Workspace` получает `onJump(row)`:

1. каретка — существующим механизмом `reveal` (`Workspace.tsx`) по `row.place.line` /
   `row.place.column` открытой заметки: `selection`, `scrollIntoView`, `view.focus()`. Если
   014 уже обернула `reveal` историей переходов — через её обёртку;
2. предпросмотр, если показан и в нём есть собранный документ: `locateHeading(
   document.pages.map(p => p.text_runs), outline, row.key)` → `useScrollAnchor.restore(
   resolved, 0)` через запрос, который принимает `PreviewPane`. `null` — предпросмотр не
   двигается;
3. в подаче шторкой — закрыть шторку.

Шаг 1 выполняется синхронно с жестом и не ждёт шага 2.

## Шторка для узкого окна (`ui/src/note-panel/NotePanelDrawer.tsx`)

Макет 1b. Подача **всей** колонки заметки, когда ширина `.ts-body` меньше 1100px и больше
720px (research.md §11): панель 280px справа поверх редактора на скриме.

- Шапка: название режима + метка `esc`; ниже — поле фильтра (у режима «Структура»); подвал:
  «↑↓ навигация · ↵ перейти · esc закрыть».
- Открытие ставит фокус в поле фильтра; `Esc` и клик по скриму закрывают и возвращают фокус
  в редактор; фокус заперт внутри шторки, пока она открыта (`useDismissOnEscape`).
- При `max-width: 720px` — шторка снизу 013 с тем же содержимым режима.
