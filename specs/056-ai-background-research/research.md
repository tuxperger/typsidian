# Research: Фоновое исследование

## §1. Поиск в вебе — только у провайдера

**Decision**: веб-исследование — запрос к подключённой модели с её встроенным серверным
инструментом поиска: у Anthropic — серверный инструмент веб-поиска API сообщений, у OpenAI —
инструмент поиска API ответов. Своему адресу поиск недоступен (Edge Case). Точные имена и
версии инструментов, формат цитат и цена поиска сверяются с живой документацией при
реализации (задача T002, как 050 T010) и записываются сюда.

**Rationale**: принцип IX — данные идут только настроенному провайдеру; отдельный поисковый
сервис потребовал бы MAJOR-поправки (clarify спеки).

## §2. Задание исследования

**Decision**: общий реестр фоновых заданий 054 (`ai/knowledge/jobs.rs`) выносится в
`ai/jobs.rs` и получает вид `Research`. Задание: событие `ResearchStarted { id, kind: Web|Pdf,
question, path? }` в файле урока, затем ход без потока в интерфейсе (прогресс — число
найденных источников), итог `ResearchDone { id, note, sources }` или `ResearchFailed`.
Предел одновременных — `research_parallel` (по умолчанию 2), остальные в очереди.

## §3. Кто отправляет

**Decision**: учитель — инструментом `research { question }` (виден, только если поиск
включён и доступен) или `study_pdf { path, question }`; пользователь — полем «Исследовать…».
Ход учителя после вызова не ждёт результата: инструмент сразу отвечает «запущено». Готовый
результат учитель получает в следующем ходе как событие с изложением.

## §4. Результат — заметка Typst

**Decision**: модель сдаёт результат инструментом `submit_research { paragraphs[], sources[{
title, url? , pages? }] }`; ядро собирает заметку Typst с экранированием текста (не
доверяя разметке модели) в `<lessons_folder>/Исследования/<вопрос>.typ`: вопрос, пометка
«найдено моделью», абзацы, список источников ссылками. Конституция: записи модели — файлы
vault.

## §5. PDF

**Decision**: текст страниц — модуль 055 `pdf_text`; файл — через `check_access_in` 050;
оценка объёма и стоимости до отправки (FR-003), как оценка импорта 055. Источники — номера
страниц.

## §6. Прерывание

**Decision**: задание, оставшееся `Running` в файле урока без итога при открытии, становится
`Interrupted` (FR-007); повтор — новое задание с тем же вопросом.
