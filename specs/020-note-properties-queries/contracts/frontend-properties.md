# Contract: интерфейс свойств и выборок

Макет — временный, https://claude.ai/code/artifact/e74f2c04-a4d7-473a-9f18-a866396d4dc0.
Тексты — `ui/src/i18n/locales/{ru,en}/properties.ts`; стили — токены.

## Режим «Свойства» колонки заметки (B1, B2)

- `ui/src/note-panel/properties/PropertiesMode.tsx` регистрируется в `noteModes`
  `Workspace.tsx` рядом с `links` (и `outline` 015, если есть).
- Источник — `properties.read(text)` по остановке набора (250 мс), как у оглавления 015.
- Строка: значок вида, ключ, редактор значения по виду (текст — поле, число — поле с
  проверкой, дата — поле даты, флажок — переключатель, список/теги — фишки с «+»).
- Изменение → `properties.edit` → применение `EditOutcome` к редактору тем же путём, что
  параметры элемента 008.
- `editable = false` → плашка B2 с причиной и «Перейти к записи», поля только для чтения.
- Клик по тегу → поиск с условием «тег» (B3).
- «Сведения о файле» — из `Note` (папка, изменена, создана).

## Поиск (B3)

`SearchOverlay.tsx`: фишки условий над строкой; разбор `тег:`, `статус:`, `папка:` в строке
запроса делает ядро (`search::parse_conditions`); результат — `vaultSelect` при пустом тексте
и обычный поиск с `properties` при непустом. `Mod+Enter` → форма B4 с условиями.

## Форма выборки (B4)

Пункт «Выборка» в меню вставки 008; форма — `ElementParams` 008 с новыми видами полей
«условия», «порядок», «столбцы» (`ui/src/editor/params/`). Вставка добавляет строку
`#import` в начало заметки, если её нет, и пишет `select.typ`, если его нет (§10).
Счётчик «Сейчас подходят N заметок» — `vaultSelect`.

## Предпросмотр (B5, B6)

`useCompiledDocument` передаёт в запрос сборки флаг «нужны входы выборок»; ядро само
считает входы. Событие изменения индекса свойств → пересборка открытой заметки с блоками.
