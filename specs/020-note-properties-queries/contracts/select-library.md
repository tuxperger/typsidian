# Contract: библиотека `select.typ`

Путь — `.typsidian/lib/select.typ` в корне vault. Текст — константа ядра; первая строка —
`// typsidian-select v1`.

```typst
#let select(where: (:), sort: none, columns: ("название",), limit: 50, view: "table") = { … }
```

Поведение:

1. Ключ — канонический текст аргументов (ядро строит его так же, `select_blocks`).
2. `sys.inputs.at("typsidian-select", default: none)`:
   - `none` → блок с рамкой: «Выборка показывается в Typsidian» и условия словами (B6);
   - строка JSON → разбор, запись по ключу: `rows` пусты → «Нет заметок по выборке» и условия;
     иначе таблица (`view: "table"`) или маркированный список (`"list"`).
3. Ячейки: текст как есть, даты — `ДД.ММ.ГГГГ`, флажок — ✓/пусто, список — через запятую,
   пусто — «—»; название — `link` на путь заметки в форме ссылок vault 013.
4. Подписи на языке документа (`text.lang`: `ru` — по-русски, иначе по-английски).

Совместимость: `v2` — новый файл с новой строкой версии; старый `v1` перезаписывается,
только если его текст совпадает с эталоном `v1` (research.md §10).
