# Quickstart: свойства и выборки

## 1. Ядро

```bash
.specify/scripts/typsidian/gates.sh core     # properties_native, properties_wasm
```

## 2. Web — сценарий

```bash
nix develop -c pnpm dev
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/properties.mjs --opfs-vault --shot /tmp/props.png
```

Сценарий: три заметки; через колонку «Свойства» первой добавить тег `проект` и
`статус: в работе` → запись в тексте, сборка без ошибок, в документе её нет. Двум другим —
тег вручную в тексте. Клик по тегу → в поиске три заметки. Новая заметка «Обзор» →
меню вставки → «Выборка» по тегу, столбцы «название, статус» → таблица из трёх строк.
Добавить тег четвёртой заметке → строка появилась ≤2 с без правки блока (SC-002).

## 3. Вне приложения (SC-003)

```bash
nix develop -c typst compile --root <vault> <vault>/Обзор.typ /tmp/obzor.pdf
```

Документ собирается; на месте блока — замещающий текст с условиями.

## 4. Масштаб (SC-001)

Бенч ядра на 10 000 заметок с 5 свойствами: отбор по тегу ≤300 мс (native и wasm).

## 5. Неоднозначная запись

`tags: базовые + ("срочно",)` → плашка «только для чтения», форма выключена, файл не меняется.
