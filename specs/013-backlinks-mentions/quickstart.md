# Quickstart: проверка обратных ссылок и упоминаний

Все команды — из корня репозитория внутри `nix develop` (cargo-команды строго по одной, без
таймаутов). Если wasm-тесты падают с «http status: 404» — запускать через
`env -u LD_LIBRARY_PATH`.

## §1. Ядро

```sh
nix develop --command cargo test -p typsidian-core --lib graph
nix develop --command cargo test -p typsidian-core --lib links
nix develop --command cargo test -p typsidian-core --test links_native --test settings_native
nix develop --command cargo build -p typsidian-core --target wasm32-unknown-unknown
nix develop --command bash -c "cd packages/core && wasm-pack test --headless --chrome -- --test links_wasm --test settings_wasm"
nix develop --command cargo test -p typsidian-shell
```

Что доказывают тесты (`links_cases`, оба таргета):

- `link_sites` и прежний `extract_links` согласованы; ссылка на доску разрешается.
- Обратные ссылки: группировка, порядок строк по тексту, порядок групп по близости папки,
  порции, цель не источник, источник сверх предела — группа с `problem`, отставший индекс
  не даёт пустой группы (FR-001, FR-002, FR-005, FR-006).
- Упоминания: регистр, границы слова («Кот»/«который»), вне ссылок, короткое название,
  доски не просматриваются, проход порциями доходит до `Finished`, `cancel` останавливает
  чтение (FR-010…FR-012).
- «Связать»: файл отличается только упоминанием; `Stale` при сдвиге и при `Conflict`;
  `ReadOnly`; `EditorEdit` без записи на диск; `UnsavedElsewhere`; одноимённые заметки в
  разных папках получают ссылку на нужную (FR-013…FR-018, SC-005, SC-006).
- Состояние колонки: умолчания, негодное значение в файле, запись только в устройство.

## §3. Web в браузере (сценарий и снимок)

```sh
nix develop -c pnpm dev                                   # в фоне, :3000
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/note-links.mjs --opfs-vault --shot /tmp/links-1a.png
```

Сценарий создаёт vault макета (`Диссертация/Проект Альфа.typ`, `Методология.typ` с тремя
ссылками, `Результаты.typ` с упоминанием, `Заметки/Лекция_12.typ` со ссылкой от корня,
`Заметки/Идеи_экспериментов.typ` с упоминанием в другом регистре) и проверяет:

1. US1: открыть «Проект Альфа», `Ctrl+Shift+L` → колонка; группы и числа как на макете 1a;
   клик по фрагменту «Методология» открывает её, каретка на ссылке.
2. US2: дописать через OPFS ссылку в `Результаты.typ` → строка появляется без действий;
   перейти к другой заметке → связи другой заметки.
3. US3: раскрыть «Упоминания» → две группы; «Связать» у «Результаты» → в файле
   `[[Проект Альфа]]`, остальной текст побайтно прежний; строка переехала в обратные ссылки.
4. Изменить `Идеи_экспериментов.typ` через OPFS так, чтобы упоминание сдвинулось, не
   дожидаясь обновления нажать «Связать» → «устарело», файл не изменён.
5. Перезагрузить страницу → колонка показана, упоминания раскрыты (FR-021).
6. Окно 360px шириной → колонки нет, кнопка в шапке открывает шторку (макет 1c); переход
   по строке закрывает её.

Снимки 1a (колонка), 1b (пусто / проход / «устарело») и 1c (360px) сверяются с макетом
глазами; расхождения сверх research.md §16 — дефект. В консоли не должно быть ошибок.

## §4. Только чтение и короткое название

Вручную в web: vault, открытый без права записи → «Связать» недоступна, причина названа.
Заметка `Яд.typ` → вместо списка упоминаний пояснение.

## §5. Desktop и Android

`nix develop -c pnpm --filter desktop tauri dev`: шаги 1–5 из §3 на настоящей папке, внешняя
правка — другим редактором. Android — сборка `apps/mobile`, шаги 1, 3 и 6 (папка vault
фиксирована: `Documents/Typsidian`). iOS-оболочки нет — **не проверяется**, в результатах
писать «не проверено».

## §6. Замеры

Vault из 5 000 заметок (генерируется скриптом сценария), 300 из них ссылаются на одну:

- SC-001: от открытия заметки до первой порции обратных ссылок — ≤ 300 мс;
- SC-002: от клика по фрагменту до каретки на ссылке в открывшейся заметке — одно действие,
  ≤ 1 с;
- SC-004: проход упоминаний — ≤ 3 с; во время прохода задержка ввода в редакторе на глаз
  отсутствует (на web зафиксировать фактическое время; промах — подбор бюджета шага,
  research.md §7);
- SC-003: от сохранения до появления ссылки в панели — ≤ 2 с.

Результаты и непроверенное — в конец `tasks.md`.
