# Quickstart: проверка переноса в дереве файлов

Все команды — из корня репозитория внутри `nix develop` (cargo-команды строго по одной,
без таймаутов). Если wasm-тесты падают с «http status: 404» — запускать через
`env -u LD_LIBRARY_PATH`.

## Ядро

```sh
nix develop --command cargo test -p typsidian-core --lib relocate
nix develop --command cargo test -p typsidian-core --test relocate_native
nix develop --command cargo build -p typsidian-core --target wasm32-unknown-unknown
nix develop --command bash -c "cd packages/core && wasm-pack test --headless --chrome -- --test relocate_wasm"
```

Что доказывают общие сценарии (`tests/common/relocate_cases.rs`, оба таргета):
- цели: нет родителя, самой папки, потомков, служебной папки; корень первым; фильтр по
  имени и пути без учёта регистра;
- отказы: `SamePlace`, `IntoItself`, `NameConflict` (в том числе для папки снимков),
  `NotFound`, `TargetNotFound`, `AccessDenied` — и что на диске ничего не изменилось;
- перенос заметки, доски, папки с вложенными папками и невидимыми файлами: побайтное
  равенство, источника нет, индекс под новыми путями;
- папка снимков одиночной заметки едет с ней (обе раскладки);
- пометка раздела едет с папкой и с вложенными;
- несохранённый буфер и конфликт остаются за заметкой под новым путём;
- разрываемые ссылки: входящие, собственные относительные, корневые; ссылки внутри
  переносимой папки не разрываются;
- собственный перенос не порождает событий внешнего удаления;
- `undo` возвращает исходное состояние; занятое прежнее место — `NameConflict`;
- web: отмена на середине копирования оставляет vault прежним.

## UI

```sh
.specify/scripts/typsidian/gates.sh all
scripts/check-i18n.sh
nix develop -c pnpm dev    # в фоне
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/tree-move.mjs --opfs-vault --shot /tmp/tree-move.png
```

Сценарий `tree-move.mjs` создаёт vault («Курсовая/Главы», «Лекции», «Входящие»,
заметки в корне), затем:

1. тащит `Входящие/идея.typ` на «Главы» — снимок с подсветкой цели и ярлыком; после
   броска заметка в `Курсовая/Главы`, сообщение «Перенесено в Курсовая/Главы»;
2. жмёт «Отменить» — заметка снова во «Входящие»;
3. открывает заметку, печатает текст без сохранения, переносит её — редактор показывает
   тот же текст, шапка — новый путь;
4. тащит «Лекции» над «Лекции/Матанализ» — подсветки нет, после броска дерево прежнее;
5. переносит `план.typ` из корня в «Курсовая», где есть `план.typ` — сообщение о занятом
   имени, оба файла на месте;
6. переносит заметку, на которую ссылается другая, — диалог со списком; «Отмена»
   оставляет всё как было;
7. открывает «Переместить в…» с клавиатуры, набирает «гл», Enter — заметка в «Главы»;
8. Escape во время жеста — ничего не перенесено.

Снимки шагов 1, 4, 6, 7 сверяются с артбордами макета: состав, порядок, подсветка.

## Вручную (нельзя автоматизировать здесь)

- **Desktop** (`nix develop -c pnpm --filter desktop tauri dev`): перенос папки с 1 000
  файлов — не дольше 5 с (SC-005); после переноса наблюдатель не показывает «изменено
  снаружи»; перенос открытой заметки с несохранёнными правками.
- **Android**: прокрутка дерева не начинает жест; удержание 400 мс поднимает строку;
  «Переместить в…» из меню «⋯».
- **Читалка экрана**: объявления захвата, цели и итога.
