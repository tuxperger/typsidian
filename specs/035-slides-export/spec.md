# Feature Specification: Экспорт презентации

**Feature Branch**: `035-slides-export`

**Created**: 2026-10-21

**Status**: Draft

**Priority**: P3

**Summary**: Презентацию можно отдать файлом: PDF со слайдами и, по желанию, страницами заметок докладчика, или набор картинок слайдов — для показа на чужом компьютере.

**Input**: User description: "Экспорт презентации (019) в PDF с заметками докладчика и в изображения слайдов."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - PDF с заметками докладчика (Priority: P1)

Из режима показа (019) — «Экспорт…»: PDF только слайдов, PDF «слайд + заметки докладчика
под ним» или файл заметок для pdfpc рядом с PDF.

**Acceptance Scenarios**:

1. **Given** презентация с заметками докладчика, **When** выбран «PDF с заметками», **Then**
   каждая страница — слайд и его заметки; без заметок — только слайды.
2. **Given** выбран «для pdfpc», **Then** рядом с PDF лежит файл заметок, который pdfpc
   открывает вместе с ним.

---

### User Story 2 - Картинки слайдов (Priority: P2)

Экспорт в PNG или SVG — по файлу на слайд с номером в имени, выбранного разрешения.

### Edge Cases

- Слайды с пошаговым показом — в экспорт попадает последний шаг (или все шаги — выбор).
- Ошибка сборки — экспорт не начинается, причина названа (как 009).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Презентацию MUST можно экспортировать в PDF слайдов, PDF со страницами заметок
  докладчика и PDF с файлом заметок для pdfpc.
- **FR-002**: Презентацию MUST можно экспортировать картинками слайдов PNG/SVG.
- **FR-003**: Пошаговые слайды MUST экспортироваться по выбору: последний шаг или все.
- **FR-004**: Папка экспорта — та же, что у PDF (009); одинаково во всех оболочках.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Число страниц/файлов экспорта равно числу слайдов (или шагов) в 100% случаев.
- **SC-002**: Файл заметок для pdfpc открывается pdfpc без правок.

## Assumptions

- Зависит от 019 (режим показа, заметки докладчика) и 009 (экспорт PDF).
