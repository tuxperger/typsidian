# Quickstart: проверка вкладок и разделения

Команды — из корня репозитория, тулчейн только через `nix develop -c …`; cargo — по одной.
Если wasm-тесты падают «http status: 404» — запускать через `env -u LD_LIBRARY_PATH`.

## 0. Гейты

```bash
.specify/scripts/typsidian/gates.sh core    # сборка под оба таргета, cargo test, wasm-bindgen-test
.specify/scripts/typsidian/gates.sh ui      # tsc strict, хардкод интерфейса
```

Ожидается: таблица `packages/core/tests/common/workspace_cases.rs` зелёная в
`workspace_native.rs` и `workspace_wasm.rs`.

## 1. Vault для проверки

Папка с `Диссертация/Введение.typ`, `Диссертация/Результаты.typ`, `Диссертация/План.typ`,
`Заметки/План.typ`, `Схема стенда.excalidraw`; во «Введение» — ссылка `[[Результаты]]`, в
«Результаты» — `[[План]]`. Web: `nix develop -c pnpm dev`, затем
`nix develop -c node scripts/dev/browser.mjs http://localhost:3000 scripts/dev/scenarios/tabs.mjs --opfs-vault --shot <снимок.png>`.

## 2. US1 — вкладки

1. Открыть три заметки из дерева → три вкладки, активна последняя.
2. Поставить каретку в середину первой, прокрутить, уйти и вернуться → каретка, выделение и
   прокрутка прежние.
3. Открыть уже открытую заметку → новой вкладки нет.
4. Закрыть активную → активна та, что была перед ней.
5. Открыть обе «План» → у вкладок подписи `Диссертация/` и `Заметки/`.
6. Набрать текст и сразу закрыть вкладку → текст в файле.
7. Сделать папку vault недоступной на запись, набрать текст, закрыть → вкладка осталась,
   показано «Вкладка не закрыта» с причиной.
8. Открыть 12 заметок → полоса прокручивается, активная видна.
9. Изменить снаружи заметку неактивной вкладки с несохранёнными правками → на вкладке
   «конфликт», диалог появляется при переходе на неё.
10. Открыть доску → вкладка с признаком «доска».

## 3. US2 — история

`Введение` → по ссылке `Результаты` → по ссылке `План`. `Mod+Alt+[` дважды → `Введение`,
каретка на ссылке; `Mod+Alt+]` → `Результаты`; открыть другую заметку → «›» приглушена.
Закрыть вкладку `Результаты`, «Назад» → открылась заново. Удалить `План` снаружи, «Назад»
через него → пропущен. Сочетания проверить в русской раскладке.

## 4. US3 — две группы

`Mod+Alt+\` → вторая группа с той же заметкой. Набор в одной группе виден в другой сразу;
`Ctrl+Z` в группе отменяет своё. Каретка в другой группе → предпросмотр и колонка заметки
(013) показывают её заметку, линия активной вкладки оранжевая там. Перетащить вкладку на
другую полосу; `Mod+Alt+Shift+\`. Сдвинуть границу, перезапустить — доля сохранена. Закрыть
последнюю вкладку группы → одна группа. Сузить окно до 880 px → одна полоса с вкладками
обеих групп, «◫» недоступна; расширить → две группы на месте.

## 5. US4 — перезапуск

Пять вкладок в двух группах, перезагрузить страницу / перезапустить приложение → вкладки,
порядок, группы, активная на месте. Удалить одну заметку при закрытом приложении → её вкладки
нет, сообщений нет. Web и desktop: переключиться на второй vault и обратно → у каждого свой
набор. Испортить ключ `workspaces` в файле настроек устройства → vault открывается без
вкладок.

## 6. Измерения

Бюджеты времени сценарий проверяет только на рабочей сборке — dev-сборка React вдвое-втрое
медленнее (переключение 50–175 мс против 15–50 мс), и там замеры только печатаются:

```bash
nix develop -c sh -c 'cd apps/web && pnpm build && pnpm start -p 3100'   # в фоне
TABS_BUDGETS=1 nix develop -c node scripts/dev/browser.mjs http://localhost:3100 \
    scripts/dev/scenarios/tabs.mjs --opfs-vault
```

- SC-001: сценарий `tabs.mjs` замеряет время от щелчка по вкладке до фокуса в редакторе —
  не больше 100 мс, в том числе во время сборки предпросмотра.
- SC-002: 50 вкладок, задержка ввода против одной вкладки — в пределах 10 %.
- SC-006: правка в группе видна во второй в том же кадре.
