# Quickstart: Закладки

1. Дерево → меню «Введение» → «В закладки»; повтор — без дубля.
2. Оглавление → заголовок «Выборка» → «В закладки»; поиск «теплопроводн» → «В закладки»;
   меню папки «рисунки» → «В закладки».
3. Щелчки: заметка открыта; раздел — на месте заголовка; поиск — окно с запросом; папка —
   раскрыта в дереве.
4. «＋ группа» → «Глава 2»; перетащить закладку в группу; Alt+↓; свернуть группу; перезапуск
   — порядок и группы на месте (`.typsidian/vault.json`).
5. Переименовать «Введение» → закладка ведёт на новое имя; удалить заметку — «недоступна».
6. Тесты: `cargo test --test bookmarks_native`, `wasm-pack test` (`bookmarks_wasm.rs`);
   сценарий `scripts/dev/scenarios/bookmarks.mjs`.
