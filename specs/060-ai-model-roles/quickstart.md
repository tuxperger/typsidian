# Quickstart: модели по ролям

```bash
nix develop -c cargo test -p typsidian-core --test ai_native roles
```

Извлечению назначено своё подключение → запрос извлечения уходит на его адрес с его ключом,
журнал показывает роль и модель; удалённое подключение → `fallback`; при умолчаниях тело
запроса урока совпадает с 051 (SC-003); `cache: Long` для Anthropic — пометки кэша в теле,
для своего адреса — недоступно.

Браузер: настройки → «Модели по ролям», сверка с артбордами A–D.
