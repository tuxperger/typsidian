# Data Model: Демо-режим сервера

## accounts (новые столбцы)

| Поле | Тип | |
|---|---|---|
| `expires_at` | INTEGER NULL | Гость: когда удалить (секунды Unix); `NULL` — обычный аккаунт |
| — | | Адрес гостя не хранится; предел по адресу — таблица `demo_starts (ip_key, at)`: ключ сети с секретом сервера |

## DemoConfig (`[demo]` файла настроек)

| Ключ | По умолчанию |
|---|---|
| `ttl_minutes` | 60 |
| `quota_mb` | 50 |
| `per_ip_per_hour` | 5 |
| `max_guests` | 200 (не больше 240) |
| `vault` | встроенный демо-vault |

## ShellCapabilities (ядро)

| Поле | | |
|---|---|---|
| `remote` | bool, по умолчанию `true` | Можно подключать удалённый репозиторий |
