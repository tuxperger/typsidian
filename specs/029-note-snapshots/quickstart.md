# Quickstart: Локальные снимки заметок

1. Vault без git. Открыть «Введение», дописать строку, сохранить; подождать интервал
   (в настройках vault — 1 минута), стереть половину текста, сохранить.
2. Палитра → «История заметки»: снимки «открытие», «сохранение»; у каждого время и +/− строк.
3. Выбрать первый снимок — различия с текущим текстом; «Вернуть эту версию» — текст равен
   снимку байт в байт, Ctrl+Z возвращает стёртое, в истории появился «перед возвратом».
4. Удалить заметку из дерева → палитра «Недавно удалённые» → «Восстановить» — заметка на
   прежнем месте; создать заметку с тем же именем и удалить снова — восстановление
   предлагает новое имя.
5. Настройки vault → «Снимки заметок»: срок, интервал, «Очистить» с подтверждением.
6. Сценарий: `nix develop -c node scripts/dev/browser.mjs http://localhost:3000 scripts/dev/scenarios/snapshots.mjs --opfs-vault`.
