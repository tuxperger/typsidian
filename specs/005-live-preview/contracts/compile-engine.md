# Contract: Поверхность сборки в ядре

**Feature**: [../spec.md](../spec.md) | **Plan**: [../plan.md](../plan.md)

Что `packages/core` обещает вызывающей стороне. Формы даны на Rust; в TypeScript они приходят
порождёнными (принцип IV), рукописных дубликатов нет.

## Трейт исполнителя сборки

Единственный платформенный шов фичи. Всё остальное — общий код.

```rust
/// Исполнитель синхронной сборки вне UI-потока (research.md §3).
///
/// На web — Web Worker со своим экземпляром ядра, на native — отдельный поток.
/// Вызывающий код НЕ ветвится по платформе.
pub trait CompileExecutor: Send + Sync {
    /// Запускает сборку снимка. Возвращает дескриптор для отмены.
    fn spawn(&self, job: CompileJob) -> CompileHandle;
}

pub struct CompileHandle { /* ... */ }

impl CompileHandle {
    /// Отменяет сборку.
    ///
    /// На web отмена настоящая: воркер завершается вместе с вычислением.
    /// На native вычисление доигрывает до конца, но его результат отбрасывается
    /// и наверх не попадает. Наблюдаемое пользователем поведение одинаково
    /// (plan.md → Complexity Tracking).
    pub fn cancel(self);
}
```

**Гарантии**:
- `spawn` не блокирует вызывающий поток ни на одном таргете (FR-007).
- После `cancel` результат этой сборки не появится ни в одном событии (FR-011).
- Ни `spawn`, ни `cancel` не изменяют ни одного файла vault (FR-026).

## Заявка на сборку

```rust
pub struct CompileJob {
    /// Заметка — точка входа.
    pub note_path: PathBuf,
    /// Текст из редактора, включая несохранённые правки (FR-002).
    /// Файл на диске при этом не читается и не изменяется.
    pub source_text: String,
    /// Версия текста; результат помечается ею (research.md §9).
    pub revision: u64,
    /// Предел времени. По умолчанию 10 секунд (FR-026).
    pub time_budget: Duration,
}
```

**Гарантия по FR-002**: сборка идёт из `source_text`, а не из файла. При неразрешённом
конфликте фичи 001 сюда попадает версия пользователя — та, что в редакторе (spec.md →
Assumptions).

## Фаза резолва

```rust
/// Источник байтов для снимка зависимостей.
///
/// Реализуется поверх существующего `VaultBackend` фичи 001 — своего доступа к
/// файлам эта фича не заводит (принцип I).
#[async_trait]
pub trait DependencyResolver {
    /// Читает файл vault. Путь уже проверен на принадлежность vault.
    async fn read(&self, path: &Path) -> Result<Bytes, ResolveError>;

    /// Встроенный набор шрифтов приложения (FR-027).
    async fn builtin_fonts(&self) -> Vec<Bytes>;

    /// Шрифты, лежащие в папке vault (FR-027, FR-029).
    async fn vault_fonts(&self) -> Vec<(PathBuf, Bytes)>;
}

pub enum ResolveError {
    NotFound,
    Unreadable,
    AccessDenied,
    OutsideVault,   // FR-023
    TooLarge,       // наследуется от предела фичи 001 (FR-030)
}
```

**Гарантии**:
- `OutsideVault` возвращается до чтения: за пределы папки vault обращения не происходит
  (FR-023). Ограничение продублировано структурно самим `VirtualPath` (research.md §8).
- Каждая `ResolveError` доходит до пользователя названной, с именем конкретного файла —
  общая «ошибка сборки» запрещена (FR-021).

## Результат

```rust
pub fn compile(job: CompileJob, snapshot: DependencySnapshot) -> CompiledDocument;
```

Форма `CompiledDocument`, `RenderedPage`, `Diagnostic` — в [data-model.md](../data-model.md).

**Гарантии**:
- `outcome == Succeeded` ⟹ в `diagnostics` нет ни одной записи серьёзности `Error`.
- `pages` содержит **все** страницы документа по порядку, каждую со своим `digest`. Ядро
  ничего не фильтрует: `CompiledDocument` всегда описывает документ целиком, иначе первая
  сборка и переоткрытие заметки требовали бы отдельного пути. Пропуск неизменившихся страниц —
  забота UI, который сравнивает `digest` с уже показанным (research.md §5).
- Диагностики отсортированы по `(path, byte_range.start)` (FR-016).
- Предупреждения приходят в том же списке с `severity: Warning` и не мешают `Succeeded`
  (FR-018).

## Шрифты

```rust
/// Набор, доступный документу: встроенный + из папки vault.
/// Системные шрифты ОС не используются (FR-027).
pub struct FontSet { /* ... */ }

impl FontSet {
    /// Шрифты, запрошенные документом, но отсутствующие в наборе.
    /// Документ при этом собирается с подстановкой (FR-028).
    pub fn missing(&self) -> &[String];
}
```

**Гарантия по FR-028**: отсутствие шрифта **никогда** не переводит сборку в `Failed`. Она
завершается `Succeeded`, а недостающие шрифты называются поимённо предупреждением.

## Пределы

| Предел | Значение | Требование |
|--------|----------|------------|
| Время сборки | 10 с | FR-026 |
| Итераций резолва | 8 | research.md §2 |
| Размер заметки | наследуется от фичи 001 | FR-030 |
| Потолок гарантий времени | 50 страниц | SC-001 |

Превышение потолка в 50 страниц — **не** отказ: документ собирается и показывается, снимаются
только временные гарантии (spec.md → Assumptions).
