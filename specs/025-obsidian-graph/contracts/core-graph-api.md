## Тесты (оба пути, `tests/common/graph_cases.rs`)

- узлы и связи из индекса; петля и ссылка в никуда отброшены; пара ссылок A→B и B→A — одна
  связь с `both_ways`;
- `[[путь|текст]]` (021) — та же цель;
- `show_orphans=false` убирает заметки без связей; `degree` — после фильтра;
- вложения: `#image("a.png")` и снимок доски; `show_attachments` включает;
- теги из свойств 020; `show_tags`;
- фильтр: текст по имени/пути, `тег:`, `папка:`; связь — только если оба конца прошли;
- группы: первая подходящая;
- локальный граф: глубина 1/2/3, связи в обе стороны, центр без связей — один узел;
- переименование заметки меняет `id`, связи сохраняются;
- настройки: умолчания, неизвестные значения, запись не трогает прочие ключи;
- бенч `graph_view`: 5 000 / 15 000 — бюджет research.md §9.
