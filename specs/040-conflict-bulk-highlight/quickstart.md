# Quickstart: проверка 040

## Ядро

```bash
.specify/scripts/typsidian/gates.sh core     # cargo test (native) + wasm-bindgen-test
```

Ожидается: проходят `merge_view_native`/`merge_view_wasm` и новые случаи пачки в
`sync_native`/`sync_wasm`.

## Интерфейс в браузере

```bash
nix develop -c pnpm dev
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/sync-merge.mjs --opfs-vault --shot /tmp/merge.png
```

Сценарий включает историю, делает снимок заметки, кладёт рядом конфликтную копию
Syncthing с правками в двух местах и одну конфликтную копию, которая совмещается сама.
Дальше он открывает панель синхронизации и проверяет:

1. В списке 2 конфликта с бейджами «N спорных» и «совместится само».
2. «Принять совмещённые» с подтверждением решает один конфликт, второй остаётся в списке.
3. В редакторе слияния есть легенда, строки колонок помечены маркерами `<` и `>`.
4. «Везде их» выбирает «их» во всех участках, и результат помечен `>`.
5. Правка строки результата помечает её `✎`. После этого «Везде своё» просит
   подтверждение.
6. Ошибок в консоли нет.

## Вручную на рабочем столе

Конфликт получения из 011 quickstart (два клона одного удалённого репозитория). Отметить
все конфликты, нажать «Взять их», подтвердить. Получение завершается, панель показывает
«актуально».
