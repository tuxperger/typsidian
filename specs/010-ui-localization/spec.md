# Feature Specification: Мультиязычный интерфейс

**Feature Branch**: `010-ui-localization`

**Created**: 2026-09-29

**Status**: Draft

**Input**: User description: "Мультиязычность интерфейса Typsidian. Пользователь выбирает язык интерфейса приложения; все тексты интерфейса (меню, панели, настройки, диалоги, подсказки, палитра команд, сообщения об ошибках и предупреждениях, включая сообщения, приходящие из ядра — диагностики сборки, причины отказов vault, экспорта и загрузки шаблонов) показываются на выбранном языке. Поддерживаются русский (текущий язык интерфейса) и английский; архитектура позволяет добавить новый язык без правки кода компонентов. Язык по умолчанию определяется по языку системы/браузера, с откатом на английский для неподдерживаемых. Выбор сохраняется в настройках устройства и действует одинаково на web, desktop и Android. Смена языка применяется без перезапуска. Содержимое заметок и документов пользователя не переводится. Сообщения самого компилятора Typst остаются как есть."

## Clarifications

### Session 2026-09-29

- Q: Перерисовываются ли уже показанные сообщения об ошибках на новом языке сразу после смены
  языка? → A: Да, сразу. Сообщение приложения несёт вид и подставляемые значения, а текст
  собирается при показе — поэтому смена языка переводит всё видимое без повторения действия
  (FR-014).
- Q: Какой язык видит после обновления уже установивший приложение пользователь с
  английской системой? → A: Язык системы. Правило одно для новых и существующих установок:
  нет явного выбора — действует язык системы; миграции настроек нет (FR-008, Assumptions).
- Q: Находит ли палитра команд команды по английским названиям, когда интерфейс не на
  английском? → A: Да: поиск идёт по названию на текущем языке и по английскому (FR-024).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Интерфейс на языке системы с первого запуска (Priority: P1)

Пользователь, у которого система (или браузер) настроена на английский, впервые открывает
Typsidian и видит весь интерфейс на английском: дерево заметок, панели, палитру команд,
настройки, диалоги, подсказки и сообщения. Пользователь с русской системой видит всё
по-русски, как сейчас. Ничего настраивать для этого не нужно.

**Why this priority**: Сегодня интерфейс только русский, и для всех, кто не читает по-русски,
приложение фактически недоступно. Автоматический выбор языка снимает этот барьер без единого
действия пользователя — это и есть минимально ценный срез фичи.

**Independent Test**: Запустить приложение с чистыми настройками устройства при английском
языке системы и пройти все экраны: ни одного текста интерфейса на русском. Повторить с
русским языком системы — ни одного текста на английском.

**Acceptance Scenarios**:

1. **Given** язык системы английский и язык в настройках устройства не выбирался, **When**
   пользователь запускает приложение, **Then** весь интерфейс показан на английском.
2. **Given** язык системы русский и язык не выбирался, **When** пользователь запускает
   приложение, **Then** весь интерфейс показан на русском.
3. **Given** язык системы не поддерживается приложением (например, немецкий), **When**
   пользователь запускает приложение, **Then** интерфейс показан на английском.
4. **Given** в системе указан региональный вариант поддерживаемого языка (например,
   британский английский), **When** пользователь запускает приложение, **Then** интерфейс
   показан на этом языке (английском).
5. **Given** интерфейс на английском, **When** пользователь открывает заметку с русским
   текстом и русским именем файла, **Then** текст заметки, её имя и пути показаны как есть,
   без перевода и транслитерации.

---

### User Story 2 - Сменить язык в настройках и сразу увидеть результат (Priority: P2)

Пользователь открывает настройки, выбирает язык интерфейса из списка поддерживаемых — и весь
интерфейс, включая саму панель настроек, мгновенно переключается на выбранный язык. Выбор
сохраняется: при следующем запуске приложение открывается на выбранном языке, независимо от
языка системы. Можно вернуться к режиму «как в системе».

**Why this priority**: Автоопределение ошибается (английская система у русскоязычного
пользователя, общий компьютер). Без ручного выбора пользователь заперт в чужом языке.

**Independent Test**: При русском интерфейсе выбрать английский в настройках — интерфейс
переключается без перезапуска, открытая заметка с несохранёнными правками не теряет их.
Перезапустить приложение — интерфейс на английском.

**Acceptance Scenarios**:

1. **Given** интерфейс на русском, **When** пользователь выбирает в настройках английский,
   **Then** все видимые тексты интерфейса, включая панель настроек, становятся английскими без
   перезапуска приложения и без отдельного действия «сохранить».
2. **Given** открыта заметка с несохранёнными правками, **When** пользователь меняет язык,
   **Then** правки, положение курсора, открытые панели и состояние предпросмотра сохраняются.
3. **Given** пользователь выбрал английский при русской системе, **When** приложение
   перезапускается, **Then** интерфейс открывается на английском.
4. **Given** пользователь выбрал конкретный язык, **When** он выбирает вариант «как в
   системе», **Then** язык снова определяется по системе — сразу и при следующих запусках.
5. **Given** в списке языков, **When** пользователь смотрит на варианты, **Then** каждый язык
   назван на самом себе («English», «Русский»), чтобы его можно было найти, не понимая
   текущего языка интерфейса.

### User Story 3 - Сообщения об ошибках и диагностики на выбранном языке (Priority: P3)

Когда что-то идёт не так — файл не прочитался, папка недоступна, экспорт в PDF не удался,
шаблон не загрузился, шрифт в папке заметок повреждён, — пользователь видит причину на языке
интерфейса. Сообщения самого компилятора Typst об ошибках в тексте документа остаются в своём
исходном виде: это язык документа, а не интерфейса.

**Why this priority**: Сообщения об ошибках — место, где пользователю больше всего нужно
понять происходящее. Английский интерфейс с русскими причинами отказов хуже, чем любой из
двух языков по отдельности.

**Independent Test**: При английском интерфейсе вызвать по одному отказу каждого вида
(недоступная папка, отсутствующий связанный файл, неудачный экспорт, отключённая загрузка
шаблонов, битый шрифт) — каждая причина названа по-английски, с именем файла или шаблона.

**Acceptance Scenarios**:

1. **Given** интерфейс на английском, **When** заметка ссылается на отсутствующий файл,
   **Then** предпросмотр называет файл и причину по-английски.
2. **Given** интерфейс на английском, **When** в тексте заметки синтаксическая ошибка Typst,
   **Then** сообщение компилятора показано в исходном виде, а окружающие его подписи панели —
   по-английски.
3. **Given** на экране показаны сообщения об отказах, **When** пользователь меняет язык,
   **Then** эти сообщения показываются на новом языке без повторения действия, вызвавшего
   отказ.
4. **Given** отказ несёт имена пользователя (имя файла, путь, имя шаблона, адрес), **When**
   сообщение показано на любом языке, **Then** эти имена воспроизведены дословно.

---

### User Story 4 - Добавить новый язык, не трогая экраны (Priority: P4)

Сопровождающий проекта добавляет третий язык, предоставив только набор переводов. Новый язык
появляется в списке выбора и определяется по системе так же, как русский и английский. Если
какой-то текст ещё не переведён, пользователь видит его английский вариант, а не пустое место
или служебный идентификатор.

**Why this priority**: Двух языков хватает для запуска, но расширяемость — явное требование.
Она не видна пользователю сразу, поэтому идёт последней.

**Independent Test**: Добавить пробный язык с частью переведённых текстов — он появляется в
списке, переведённые тексты показаны на нём, непереведённые — по-английски; ни один экран при
этом не менялся.

**Acceptance Scenarios**:

1. **Given** добавлен набор переводов нового языка, **When** пользователь открывает список
   языков, **Then** новый язык в нём присутствует и назван на самом себе.
2. **Given** в наборе нового языка нет перевода для какого-то текста, **When** этот текст
   показывается, **Then** он показан по-английски.
3. **Given** в наборе переводов текст, требующий подстановки числа, **When** число меняется,
   **Then** форма слова соответствует правилам этого языка («1 заметка / 3 заметки /
   5 заметок», «1 note / 3 notes»).

---

### Edge Cases

- Хранилище настроек устройства недоступно или повреждено: язык определяется по системе,
  приложение работает; сообщение о недоступности настроек показано на этом языке.
- Язык, записанный в настройках, больше не поддерживается (например, настройки перенесены с
  более новой версии): используется язык системы с откатом на английский, настройки не
  затираются молча до явного выбора пользователя.
- Язык меняется во время идущей сборки предпросмотра, экспорта или загрузки шаблона: операция
  не прерывается, её результат и сообщения показываются уже на новом языке.
- Язык меняется, пока открыт диалог или контекстное меню: они остаются открытыми и
  перерисовываются на новом языке, введённый в поля текст сохраняется.
- Английские тексты обычно длиннее или короче русских: на минимальной ширине окна и на
  экране телефона подписи не перекрывают друг друга и не выходят за границы элементов.
- Числа, даты и размеры файлов отображаются по правилам выбранного языка.
- Встроенный редактор досок имеет собственный интерфейс: он следует языку приложения, если
  поддерживает этот язык, иначе показывается по-английски.
- Системные диалоги ОС (выбор папки) показывают заголовки приложения на языке интерфейса;
  собственные кнопки ОС остаются на языке системы.
- Журналы приложения не переводятся: их читают при диагностике, и они обязаны быть
  одинаковыми независимо от языка интерфейса.

## Requirements *(mandatory)*

### Functional Requirements

**Охват**

- **FR-001**: Каждый текст интерфейса, который формирует само приложение, MUST показываться
  на текущем языке интерфейса: меню, панели, заголовки, кнопки, подписи полей, подсказки,
  всплывающие описания, палитра команд, диалоги подтверждения, пустые состояния, индикаторы
  состояния, сообщения об ошибках и предупреждениях.
- **FR-002**: FR-001 MUST распространяться на сообщения, которые формирует логика приложения
  за пределами экранов: причины отказов при работе с папкой заметок, связанными файлами,
  настройками, экспортом, загрузкой шаблонов, шрифтами и досками.
- **FR-003**: Содержимое пользователя MUST NOT переводиться и MUST NOT изменяться: текст
  заметок, имена файлов и папок, пути, имена шаблонов, адреса, содержимое досок.
- **FR-004**: Сообщения компилятора Typst об ошибках и предупреждениях в тексте документа
  MUST показываться в исходном виде; переводятся только подписи интерфейса вокруг них.
- **FR-005**: Имена пользователя, подставляемые в сообщения (файл, путь, шаблон, адрес),
  MUST воспроизводиться дословно на любом языке.
- **FR-006**: Документ приложения MUST объявлять текущий язык интерфейса, чтобы средства
  чтения с экрана произносили тексты с правильным произношением.

**Выбор языка**

- **FR-007**: Приложение MUST поддерживать как минимум русский и английский языки
  интерфейса.
- **FR-008**: Пока пользователь не выбрал язык явно, язык интерфейса MUST определяться по
  предпочтительным языкам системы (браузера) в порядке их приоритета: берётся первый
  поддерживаемый; региональные варианты сводятся к основному языку.
- **FR-009**: Если ни один из предпочтительных языков системы не поддерживается, MUST
  использоваться английский.
- **FR-010**: Пользователь MUST иметь возможность выбрать язык интерфейса в настройках из
  списка поддерживаемых языков, а также вариант «как в системе».
- **FR-011**: Каждый язык в списке выбора MUST быть назван на самом этом языке.
- **FR-012**: Смена языка MUST вступать в силу немедленно для всего видимого интерфейса, без
  перезапуска приложения и без отдельного действия «сохранить».
- **FR-013**: Смена языка MUST NOT терять несохранённые правки, положение курсора, открытые
  панели, диалоги, введённый в поля текст и состояние идущих операций.
- **FR-014**: Сообщения, уже показанные на экране на момент смены языка, MUST показываться
  на новом языке без повторения вызвавшего их действия (за исключением сообщений компилятора
  Typst — FR-004).

**Хранение**

- **FR-015**: Выбранный язык MUST сохраняться в настройках устройства и действовать при
  следующих запусках.
- **FR-016**: Язык интерфейса MUST быть настройкой устройства и MUST NOT зависеть от того,
  какая папка заметок открыта; он MUST NOT записываться в папку заметок.
- **FR-017**: Сброс настроек устройства к значениям по умолчанию MUST возвращать режим «как в
  системе».
- **FR-018**: Если сохранённое значение языка не распознано, приложение MUST вести себя как в
  режиме «как в системе» и MUST NOT перезаписывать сохранённое значение без явного выбора
  пользователя.

**Паритет клиентов**

- **FR-019**: Для одного и того же языка тексты интерфейса и сообщения MUST совпадать на web,
  desktop и Android.
- **FR-020**: Выбор языка, автоопределение и немедленное применение MUST работать одинаково
  на всех трёх клиентах.

**Язык-зависимое оформление**

- **FR-021**: Формы слов при числах MUST следовать правилам текущего языка.
- **FR-022**: Числа, даты и размеры файлов MUST форматироваться по правилам текущего языка.
- **FR-023**: Подписи сочетаний клавиш MUST оставаться корректными на любом языке интерфейса;
  сами сочетания от смены языка MUST NOT меняться.
- **FR-024**: Поиск в палитре команд MUST находить команды по их названиям на текущем языке
  интерфейса и по английским названиям; показываются названия на текущем языке.
- **FR-025**: Встроенный редактор досок MUST показывать свой интерфейс на языке приложения,
  если поддерживает его, иначе — на английском.

**Расширяемость**

- **FR-026**: Добавление нового языка MUST сводиться к предоставлению набора переводов и MUST
  NOT требовать изменения описаний экранов и логики сообщений.
- **FR-027**: Для текста, у которого нет перевода на текущий язык, MUST показываться его
  английский вариант; пустое место или служебный идентификатор вместо текста MUST NOT
  показываться.
- **FR-028**: Полнота переводов поддерживаемых языков MUST проверяться автоматически: набор
  перевода, в котором отсутствует текст, имеющийся в английском, MUST обнаруживаться до
  выпуска.

**Надёжность**

- **FR-029**: Недоступность или повреждение настроек устройства MUST NOT мешать работе
  приложения: используется язык системы (FR-008, FR-009).
- **FR-030**: Выбор языка и его применение MUST работать при полностью отключённой сети.
- **FR-031**: Журналы приложения MUST NOT зависеть от языка интерфейса.

### Key Entities

- **Язык интерфейса**: поддерживаемый язык; имеет код, название на самом себе и правила
  форм слов при числах и форматирования чисел и дат.
- **Выбор языка**: значение настроек устройства — либо «как в системе», либо конкретный
  поддерживаемый язык.
- **Набор переводов**: соответствие между каждым текстом интерфейса и его формой на одном
  языке; английский набор — полный эталон, остальные сверяются с ним.
- **Сообщение**: текст, который приложение показывает пользователю; состоит из вида
  сообщения и подставляемых значений (имена файлов, числа), чтобы его можно было показать на
  любом языке, не повторяя действия, которое его вызвало.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: При проходе всех экранов и состояний приложения на каждом поддерживаемом языке
  доля текстов интерфейса не на этом языке равна 0% (не считая содержимого пользователя и
  сообщений компилятора Typst).
- **SC-002**: При первом запуске с русским или английским языком системы 100% пользователей
  видят интерфейс на языке системы без каких-либо действий.
- **SC-003**: Смена языка в настройках отражается на всём видимом интерфейсе не более чем за
  1 секунду, без перезапуска и без потери несохранённых правок.
- **SC-004**: Каждая причина отказа из FR-002 при английском интерфейсе названа по-английски
  и содержит имя затронутого файла, папки или шаблона.
- **SC-005**: Добавление пробного третьего языка не требует изменений нигде, кроме его
  набора переводов, и язык сразу доступен в списке выбора.
- **SC-006**: На минимальной ширине окна и на экране телефона шириной 400 точек ни на одном
  языке подписи не перекрывают друг друга и не выходят за границы элементов.
- **SC-007**: Для одного и того же языка тексты одного и того же экрана совпадают на web,
  desktop и Android в 100% проверенных случаев.

## Out of Scope

- Перевод содержимого заметок, имён файлов и документов пользователя.
- Перевод сообщений компилятора Typst и языка, на котором свёрстан документ (переносы,
  кавычки, язык текста задаются самим документом).
- Языки с письмом справа налево и зеркальная раскладка интерфейса.
- Отдельный язык для каждой папки заметок или каждого окна.
- Перевод документации проекта, спецификаций и журналов приложения.
- Изменение раскладки клавиатуры или сочетаний клавиш в зависимости от языка.

## Assumptions

- Английский — эталонный набор переводов и язык отката; русский — второй полный набор. Оба
  выпускаются полными.
- У существующих пользователей явного выбора языка нет, поэтому после обновления язык
  определяется по системе: пользователь с русской системой ничего не заметит, пользователь с
  английской системой увидит английский интерфейс и сможет вернуть русский в настройках.
- Выбор языка живёт в том же хранилище настроек устройства, что и прочие значения
  устройства из фичи 004; на клиентах, где панель настроек устройства сегодня неполная,
  переключатель языка всё равно доступен.
- Нативные сообщения оболочек (диалог выбора папки, сообщения о правах доступа на Android)
  входят в охват FR-001.
- Встроенный редактор досок поддерживает русский и английский.
- Проверка SC-001 выполняется проходом по экранам и автоматической сверкой полноты
  переводов (FR-028).

## Dependencies

- Фича 004 (настройки приложения): хранилище настроек устройства и панель настроек, куда
  добавляется выбор языка.
- Фича 006 (служебное место папки): язык остаётся на устройстве и не переезжает в папку
  заметок.
- Фичи 001, 002, 003, 005, 007, 008, 009: их пользовательские сообщения и причины отказов
  входят в охват FR-002.
