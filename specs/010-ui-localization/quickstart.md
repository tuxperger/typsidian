# Quickstart: проверка мультиязычного интерфейса (фича 010)

Все команды — внутри `nix develop`.

## 1. Автоматические гейты

```sh
cargo test -p typsidian-core                                            # native
(cd packages/core && wasm-pack test --headless --chrome -- \
   --test settings_wasm --test preview_wasm --test export_wasm)          # wasm32 (принцип II)
pnpm build:wasm                                                         # типы AppMessage → ui
pnpm typecheck                                                          # все пакеты: каталоги, AppMessage
scripts/check-i18n.sh                                                   # 0 литералов вне locales/
```

Ожидание: всё зелёное; `check-i18n.sh` печатает `i18n: ok`.

## 2. Автоопределение (US1, SC-002)

1. Удалить ключ `language` из `settings.json` устройства (или открыть web в чистом профиле).
2. Запустить web с `--lang=en-GB` (Chromium) → весь интерфейс по-английски.
3. `--lang=ru` → по-русски. `--lang=de` → по-английски (FR-009).

## 3. Переключение (US2, SC-003)

1. Открыть заметку, внести правку, не сохранять.
2. Настройки → Appearance/Внешний вид → Language → Русский.
3. Ожидание: всё видимое, включая панель настроек, по-русски за ≤1 с; правка и курсор на
   месте; в `settings.json` появился `"language": "ru"`.
4. Перезапуск → русский. Выбор «Как в системе» → ключ удалён.
5. При открытой папке заметок `.typsidian/vault.json` ключа `language` не содержит (FR-016).

## 4. Сообщения ядра (US3, SC-004)

При английском интерфейсе вызвать: `#image("нет.svg")`, `#import "@preview/nope:0.1.0"` при
выключенной автозагрузке, битый `fonts/x.ttf` в vault, экспорт в папку без прав. Каждая
причина — по-английски, с именем файла/шаблона. Сменить язык на русский — те же сообщения
по-русски без пересборки (FR-014). Синтаксическая ошибка Typst — текст компилятора как есть.

## 5. Пробный язык (US4, SC-005)

Добавить `locales/xx.ts` как `Partial<Catalog>` с двумя ключами и запись в `LANGUAGES`.
Ожидание: язык в списке под своим названием; два текста переведены, остальные английские;
других изменений в репозитории нет (`git diff --stat`).

## 6. Раскладка (SC-006)

Стенд headless Chromium (память проекта «Проверка UI без тестов»): скриншоты всех экранов
на ширине 400 px и минимальной ширине окна на `en` и `ru`; перекрытий и выхода подписей за
границы нет.

## 7. Паритет (SC-007)

Desktop (`pnpm build` в `apps/desktop`) и APK: те же экраны на `en` дают те же тексты, что
web.

## Результаты прогона 2026-09-30

Стенд: настоящая web-сборка (`next start`) + ядро wasm, `showDirectoryPicker` подменён
папкой OPFS с тремя файлами (заметка с `#image("missing.svg")`, длинное имя, доска); CDP
из node; экраны — приветствие, рабочая область, палитра, поиск, шаблоны, экспорт, граф,
контекстное меню, все разделы настроек. Детектор: выход текста за окно, перелив без
многоточия, обрезка предком с `overflow: hidden`, кириллица при `en`.

- **§1 гейты** — зелёные: `cargo test -p typsidian-core`, wasm `settings/preview/export`
  (42/27/25), `pnpm build:wasm`, `pnpm typecheck`, `check-i18n.sh` → `i18n: ok`, `pnpm build`.
- **§2 автоопределение** (чистый профиль, `--lang` + `Accept-Language`) — `en`:
  `lang="en"`, на всех экранах ни одной кириллической подписи; `ru` → `lang="ru"`; `de` →
  `lang="en"` (FR-009). `en-GB` отдельно не гонялся — сведение к основному подтегу покрыто
  `resolveLanguage`.
- **§3 смена языка** — 22–24 мс (SC-003). Найдено и исправлено: редактор пересоздавался при
  смене языка — `CodeEditor` пересобирал `EditorView` по переведённой `aria-label`, курсор и
  история терялись (FR-013). Теперь пересоздание по `documentId`, подпись — через
  `Compartment`. После исправления: тот же `.cm-editor`, правка на месте, каретка
  `3:13 → 3:13`, тот же предпросмотр; открытая доска — тот же экземпляр, подписи Excalidraw
  сменились («Выделение области» → «Selection», FR-025). Ошибок в консоли нет.
- **§6 раскладка, минимальное окно 880×560 и 1280×800, `en`/`ru`** — чисто. Исправлено в
  `app.css`: тулбары колонок (перенос кнопок из 26px, PDF и масштаб за границей колонки) —
  подписи и длинные кнопки (`ts-btn--shrink`, полный текст в `title`) сжимаются
  многоточием; строка состояния в колонке уже 420px прячет `UTF-8` и `typst`
  (`@container`). Дефекты были и на исходном русском, не только в переводе.
- **§6 раскладка, 400 px** — **не выполнено**: у приложения нет телефонной раскладки вовсе
  (в `app.css` ни одного `@media` по ширине, Android использует тот же трёхколоночный
  `Workspace`), за экран уходит почти всё на обоих языках. Это не дефект перевода, а
  отсутствующая адаптивная вёрстка — вынесено отдельно.
- **§7 паритет** — стенд собранных `apps/desktop/dist` и `apps/mobile/dist` с заглушкой
  `__TAURI_INTERNALS__`: приветствие на `en` совпадает с web дословно; выбор папки Android
  переведён на `en` и `ru`. Desktop `.deb` собран. Проверка на устройстве не проводилась —
  по USB не подключено ни одного.

## Телефонная раскладка (T057, 2026-10-20)

Уже 560 px (`PHONE_VIEWPORT_QUERY`) рабочая область показывает дерево, текст и
предпросмотр по одному; переключатель «Файлы · Текст · Вид» — внизу, открытая заметка сама
переводит к тексту. Шапка, тулбары редактора и предпросмотра и строка состояния не выходят
за экран — лишнее прокручивается вбок внутри своей строки; диалоги, шторки и палитра — во
всю ширину, меню настроек — над разделом. Стенд `scripts/dev/scenarios/phone-layout.mjs`
(400×820, web): ширина страницы 400 на всех трёх колонках на `ru` и на `en`, панель
настроек 388 px. На устройстве Android — T058.
