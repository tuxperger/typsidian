# Feature Specification: Режим клавиш Vim

**Feature Branch**: `045-vim-key-mode`

**Created**: 2026-11-01

**Status**: Draft

**Priority**: P3

**Summary**: В редакторе можно включить режим клавиш Vim, а текущий режим ввода (NORMAL, INSERT) виден в строке состояния.

**Input**: Поведение из макетов нового дизайна, отложенное фичей 044 (перевёрстка без нового поведения).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Редактирование командами Vim (Priority: P3)

Пользователь, привыкший к Vim, выбирает в настройках редактора «Режим клавиш: Vim» и
редактирует заметки командами Vim; в строке состояния — плашка текущего режима ввода.

**Independent Test**: включить Vim, отредактировать заметку командами `i`, `Esc`, `dd`,
`:w` — правки сохраняются, плашка меняется.

**Acceptance Scenarios**:

1. **Given** режим «Vim», **When** пользователь нажимает `Esc`, **Then** плашка показывает
   NORMAL, буквы не вставляются в текст.
2. **Given** режим «Обычный», **Then** плашки нет и поведение редактора прежнее.

### Edge Cases

- Сочетания приложения, конфликтующие с Vim, остаются доступными через палитру.
- На телефоне режим не предлагается: нет физической клавиатуры по умолчанию.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Настройки редактора MUST давать выбор «Обычный / Vim», выбор переживает
  перезапуск.
- **FR-002**: В режиме Vim MUST работать режимы NORMAL, INSERT, VISUAL и основные команды
  перемещения и правки.
- **FR-003**: Строка состояния MUST показывать плашку режима ввода только в режиме Vim.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Режим включается и выключается без перезапуска; в режиме «Обычный» ни одно
  прежнее сочетание не меняется.

## Assumptions

- Макет — артборд 9 (настройки) и плашка NORMAL/INSERT артбордов 1, 3, 5 фичи 044.
- Зависит от 044.
