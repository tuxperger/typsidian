# Quickstart: Битые ссылки и заметки-сироты

1. Vault с `[[Методика]]` в трёх заметках и без заметки «Методика»; «Схема стенда» —
   ссылка на несуществующую доску; `#image("нет.png")`.
2. Подвал дерева — «N битых»; щелчок открывает «Состояние ссылок».
3. Группа «Методика»: «Перенаправить на…» → «Методология» — все ссылки исправлены,
   подпись `[[Методика|методике]]` сохранена; «Отменить» — вернулось.
4. «Создать заметку» — группа исчезла. ✕ у строки — ссылка стала текстом.
5. Вкладка «Без входящих»: «Намеренно» — заметка пропала, переименование не возвращает её.
6. Сценарий: `nix develop -c node scripts/dev/browser.mjs http://localhost:3000 scripts/dev/scenarios/link-health.mjs --opfs-vault`.
