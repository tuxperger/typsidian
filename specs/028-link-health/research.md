# Research: Битые ссылки и заметки-сироты

## 1. Источник сведений

**Decision**: `link_health` берёт `backend.graph_source()` (025): заметки, доски, разрешённые
ссылки `[[…]]` и вставки `#image` из индекса, без чтения файлов. Существование цели —
по заметкам, доскам и списку файлов vault (`list()`), вложения — любые файлы, кроме
служебных. Файлы читаются только у заметок с битыми ссылками — ради строк-примеров.
**Rationale**: SC-001 на 5 000 заметок; граф уже доказал этот путь (≤ 100 мс, 025 §9).

## 2. Строки-примеры и опознание места

**Decision**: место — `BrokenSite { source, line, pieces, index }`, где `index` — порядковый
номер записи с этой целью в заметке-источнике; рядом — отпечаток текста источника
(`search::replace::digest`). Починка сверяет отпечаток (как 027): изменился — `Stale`.
Тексты открытых заметок берутся из редактора.

## 3. Починка

**Decision**: `fix_links(backend, request, editor_text) -> ReplaceNoteOutcome` (тип 027):
`Redirect { to }` переписывает цель записи `[[цель|подпись]]` через `graph::link_text`,
подпись сохраняется; `Unlink` оставляет подпись или текст цели без скобок; для вставки
`#image(...)` — убирает вызов целиком. `only: Option<u32>` — одна запись, иначе все
записи цели в заметке. Отмена — `replace_undo` 027 по `UndoRecord`.
«Создать заметку/доску» — существующее создание по пути ссылки (018 `createNote`).

## 4. Сироты и входы

**Decision**: сирота — заметка без входящих `[[…]]` и вставок от других заметок. Вход —
заметка входящих и заметки папки дневника (022, `capture_settings`) — помечены видом
`Entry` и скрываются фильтром по умолчанию. «Намеренно» — путь в `links.intentional_orphans`
настроек vault; при переименовании заметки или папки путь переезжает (как `move_sections`).

## 5. Счётчик

**Decision**: подвал дерева показывает число битых ссылок из того же `link_health`,
пересчитываемого при изменениях vault с паузой (как связи 013); ноль не показывается.
