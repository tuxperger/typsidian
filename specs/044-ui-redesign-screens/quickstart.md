# Quickstart: проверка экранов 044

```bash
nix develop -c pnpm dev
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/redesign-screens.mjs --opfs-vault --shot /tmp/044.png
```

1. Ctrl K — палитра: затемнение, «Esc» в поле, группы, совпадение выделено (артборд 3).
2. Вид «Текст», колонка заметки — справа, вкладки «Оглавление», «Ссылки · N», «Свойства» (4).
3. Сломать `#import` — карточка ошибки над бледным листом, «Перейти к строке», «1 ошибка» (5).
4. Панель синхронизации — колонка слева от текста; слияние — «свои» оранжевые, «их» синие (6).
5. Значок графа внизу дерева — граф справа от дерева, колонка «Показывать», сводка внизу (7).
6. Настройки — разделы слева, строки «название — поле — подсказка» (9).
7. «Экспорт PDF» — окно «Экспорт»: PDF / HTML / Слайды, «Что», «Куда» (10).
8. Низ дерева: «+ Заметка», граф, задачи, источники, настройки (1).
