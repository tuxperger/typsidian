# Quickstart: Синхронизация на своём сервере

1. `nix develop -c cargo run -p typsidian-server -- user add anna` и запуск сервера (037).
2. Войти, открыть vault, панель «Синхронизация» → «Включить историю»: мастер правил и первый
   снимок; в `<данные>/users/<id>/<vault>/.git` — обычный репозиторий.
3. Изменить заметку, «Снимок», «История заметки» → вернуть первую версию — текст первого
   снимка в редакторе.
4. «Подключить удалённый»: `git@host:x.git` → отказ «на сервере только HTTPS»;
   `file:///etc` → отказ; `https://10.0.0.1/x.git` → отказ (без `sync_private_remotes`).
5. `https://…` с токеном → подключено; `grep -r <токен> <данные>/users` — пусто; ответы в
   инструментах разработчика токена не содержат; `secrets.json` — права `600`.
6. Второй аккаунт: тот же vault-имя — свой id, своих секретов нет.

Сценарий: `nix develop -c node scripts/dev/browser.mjs http://localhost:8787 scripts/dev/scenarios/server-sync.mjs`.
