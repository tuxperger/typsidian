# Feature Specification: Открыть после экспорта и предупреждение о перезаписи

**Feature Branch**: `047-export-open-overwrite`

**Created**: 2026-11-01

**Status**: Draft

**Priority**: P3

**Summary**: После экспорта файл можно сразу открыть, а если файл с таким именем уже есть, окно экспорта заранее предупреждает о замене.

**Input**: Поведение из макетов нового дизайна, отложенное фичей 044 (перевёрстка без нового поведения).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Экспорт без сюрпризов (Priority: P3)

В окне экспорта пользователь включает «Открыть после экспорта»; если по пути «Куда» уже
лежит файл, под полями видно «Файл с таким именем уже есть — он будет заменён».

**Independent Test**: экспортировать заметку дважды в один путь — во второй раз видно
предупреждение; с включённым переключателем файл открывается.

**Acceptance Scenarios**:

1. **Given** файл по пути назначения есть, **Then** предупреждение видно до нажатия
   главной кнопки.
2. **Given** «Открыть после экспорта» включено, **When** экспорт завершён, **Then** файл
   открывается системной программой.

### Edge Cases

- В web «открыть» — это скачивание; переключатель там не показывается.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Окно экспорта MUST давать переключатель «Открыть после экспорта», выбор
  запоминается на устройстве.
- **FR-002**: Окно экспорта MUST предупреждать о замене существующего файла до экспорта.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: О перезаписи пользователь узнаёт до экспорта всякий раз, когда файл есть.

## Assumptions

- Макет — артборд 10 фичи 044.
- Зависит от 044.
