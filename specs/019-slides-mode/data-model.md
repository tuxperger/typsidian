# Data Model: Режим показа слайдов

**Feature**: 019-slides-mode | **Date**: 2026-10-15

Всё ниже — значения ядра (`packages/core/src/slides/`), в UI — типами `Tsify`. Хранимых данных
у фичи нет.

## PageSlideInfo

Сведения о странице собранного документа, нужные показу. `CompiledDocument.slides` — по одной
записи на страницу, в порядке `pages`; у неудавшейся сборки пусто.

| Поле | Тип | Смысл |
|---|---|---|
| `page_index` | `u32` | физический номер страницы, с нуля; совпадает с `RenderedPage.index` |
| `source_start` | `Option<SlidePlace>` | начало текста заметки на странице; `None` — на странице нет текста главного файла (research.md §1) |
| `logical_slide` | `Option<u32>` | номер логического слайда из `<pdfpc>` `LogicalSlide`, с единицы (research.md §2) |
| `notes` | `Option<String>` | заметки докладчика к странице; `None` — заметок нет |

`SlidePlace { offset: u32, line: u32, column: u32 }` — смещение в единицах UTF-16 редактора
(для сравнения с кареткой) и строка/колонка **с нуля**; `revealPlace` и `TextPlace` считают
с единицы, поэтому `useShowSession` прибавляет 1 при выходе из показа.

Правила: `slides.len() == pages.len()`; `page_index` идут подряд с нуля; `logical_slide` не
убывает по страницам (пакет так и нумерует; нарушение — номер не используется, подпись
показывает страницы).

## ShowState

Состояние показа; держит окно редактора, ядро возвращает новое значение.

| Поле | Тип | Смысл |
|---|---|---|
| `page` | `u32` | текущая страница, с нуля, `< total` |
| `total` | `u32` | число страниц сборки, на которой стоит показ |
| `started_at_ms` | `f64` | момент запуска (часы окна, `Date.now()`), для «с начала» |

Переходы: `start(slides, caret | None)` → `page = page_at_caret` или `0`;
`navigate(state, slides, action)`; `carry(state, slides)` после пересборки. При
`total == 0` показ не запускается — ядро отвечает ошибкой `EmptyDeck` (A5).

## ShowAction

`Next` · `Previous` · `First` · `Last` · `GoToSlide { number: u32 }` · `GoToPage { index: u32 }`.
`GoToPage` — щелчок по ленте вида докладчика (A7).

## SlideLabel

Подпись для счётчиков (A2, A7, A8), считается ядром.

| Поле | Тип | Смысл |
|---|---|---|
| `current` | `u32` | номер слайда (логический, если известен, иначе страница + 1) |
| `total` | `u32` | число слайдов (логических или страниц) |
| `step` | `Option<u32>` | номер шага внутри слайда, с единицы; `None` — у слайда один шаг или слайды не размечены |
| `steps` | `Option<u32>` | число шагов слайда |
| `next_page` | `Option<u32>` | страница «Дальше» для вида докладчика; `None` на последней |

## ShowSession (UI, окно редактора)

Не тип ядра — форма состояния `useShowSession` (contracts/frontend-show.md).

| Поле | Смысл |
|---|---|
| `id` | случайный идентификатор показа: имя канала и окон |
| `notePath` | заметка, с которой начат показ (research.md §7) |
| `state` | `ShowState` |
| `document` | последний удачный `CompiledDocument` этой заметки |
| `stale` | сборка текущего текста не удалась (FR-008, A4) |
| `failure` | первая ошибка, если удачной сборки не было (A5) |
| `presenterOpen` | открыт ли вид докладчика |
