# Contract: интерфейс показа

Макет — временный, https://claude.ai/code/artifact/e09bc800-3794-4acd-9101-68ec412a934a.
Стили — только токены `ui/src/styles/tokens/`, классы `.ts-show*`, `.ts-presenter*` в
`ui/src/styles/app.css`; тексты — `ui/src/i18n/locales/{ru,en}/slides.ts`.

## Запуск (A1) — `Workspace.tsx`

- Кнопка «Показ» с меню в шапке видна, когда открыта заметка `.typ` (не доска).
- Пункты: «С текущего слайда» (`Mod+Alt+P`, `CommandId::StartShow`), «С начала», «Сразу с видом
  докладчика» — последний только при `host.supports.presenter`.
- Те же пункты — в палитре команд.
- Окно не открылось → тост `slides.blocked` с действием «Открыть ещё раз».

## `useShowSession(host, preview, editor)` — окно редактора

```ts
interface ShowSessionApi {
  active: boolean;
  start(from: "caret" | "first", withPresenter: boolean): Promise<void>;
  stop(): void;              // вызывается и на `exit`/`closed`
}
```

- `start`: `slidesStart(document.slides, caret)`; нет удачной сборки → открывает окно показа
  с состоянием A5 (`failure` = первая ошибка).
- Новая удачная сборка показываемой заметки → `slidesCarry`, `deck`, `state`.
- Неудачная сборка → `state` со `stale: true` (A4).
- `stop`: `slidesCaret(slides, page)` → `reveal` в редакторе (FR-004), `end`, закрытие окон.

## `ShowView` (A2–A6)

- Слайд — `SlideImage`: SVG страницы, вписанный по `min(w/W, h/H)`, поле — `--ts-show-ground`.
- Панель внизу: назад, счётчик `SlideLabel`, вперёд, «Докладчик» (если поддерживается),
  «Во весь экран» (если окно не в полноэкранном режиме), выход. Видна при движении мыши,
  прячется через 2 с; касание экрана показывает её так же (зоны касания — только в `ShowOverlay`).
- Цифры → поле номера (A3), сброс через 3 с; `Enter` → `GoToSlide`, `Escape` → отмена.
- `stale` → плашка A4; «К ошибке» шлёт `revealError`: хозяин завершает показ и ставит
  каретку на первую ошибку.
- `failure` без страниц → A5: текст ошибки, «Вернуться к заметке» (= `exit`), «Закрыть показ».
- Web без полноэкранного режима → плашка A6 на 6 с.

## `PresenterView` (A7)

Часы (минута), время с начала `чч:мм:сс` от `started_at_ms`, счётчик, «Завершить показ»;
текущий слайд с рамкой акцента и подписью шага; «Дальше» — `label.next_page`; заметки
(`notes` текущей страницы, кегль `--text-md`), пусто без сообщений; лента страниц —
`GoToPage` по щелчку. Клавиши те же, что в окне показа.

## `ShowOverlay` (A8, Android)

Слой на весь экран поверх рабочей области; зоны касания 30 %/40 %/30 %; свайп; полоса
«Выйти» и счётчик по касанию середины на 3 с; системная «Назад» — выход.
