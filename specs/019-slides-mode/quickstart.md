# Quickstart: проверка режима показа слайдов

**Feature**: 019-slides-mode

## Подготовка

```bash
nix develop -c pnpm dev       # web на :3000, в фоне
```

Заметка-образец `доклады/показ.typ` — без пакетов, чтобы работать без сети:

```typst
#set page(width: 16cm, height: 9cm)
= Первый
Текст первого слайда.
#metadata((t: "LogicalSlide", v: 1)) <pdfpc>
#pagebreak()
= Второй
Шаг один.
#metadata((t: "LogicalSlide", v: 2)) <pdfpc>
#metadata((t: "Note", v: "Сказать про шаги.")) <pdfpc>
#pagebreak()
= Второй
Шаг один. Шаг два.
#metadata((t: "LogicalSlide", v: 2)) <pdfpc>
#pagebreak()
#image("схема.png")
#metadata((t: "LogicalSlide", v: 3)) <pdfpc>
```

## 1. Ядро — оба пути

```bash
.specify/scripts/typsidian/gates.sh core
```

Ожидается: `slides_native` и `slides_wasm` проходят (сценарии — contracts/core-slides-api.md
§ Тесты).

## 2. Web — сценарий

```bash
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/slides.mjs --opfs-vault --shot /tmp/slides.png
```

Сценарий: открыть образец, каретку на «Шаг один.» второго слайда, `Mod+Alt+P` → окно показа на
странице 2, счётчик «2 / 3 · шаг 1 из 2»; `→` → шаг 2; `End`, `Home`; набрать `3` `Enter` →
картинка; `Esc` → каретка в начале текста перед `#image`-страницей. Замеры: запуск ≤2 с,
смена ≤100 мс. Снимки сверить с A2, A3.

## 3. Вид докладчика, US3, ошибки (web, вручную)

1. Меню «Показ» → «Сразу с видом докладчика»: два окна; заметка «Сказать про шаги.» видна только
   в виде докладчика; листание в любом окне листает оба (FR-005, FR-006).
2. На слайде 2 исправить текст в редакторе → показ обновился ≤2 с, номер тот же (SC-004).
   Удалить две последние страницы, стоя на 4-й → показан последний.
3. Сломать разметку (`#set page(`) → плашка A4; «К ошибке» → редактор на месте ошибки.
4. Новая заметка с ошибкой с первого символа → «Показ» → A5 с текстом ошибки.

## 4. Настоящие пакеты (вручную, нужна сеть для первой загрузки)

Шаблон touying и polylux из 007; в каждом — `speaker-note` на слайде с `#pause`. Ожидается:
заметки в виде докладчика, шаги в подписи, номер слайда совпадает с номером на слайде.

## 5. Рабочий стол (вручную)

`nix develop -c pnpm --filter desktop dev`. С двумя мониторами окно показа открывается на
втором во весь экран, вид докладчика — на первом. Закрыть окно показа крестиком → редактор на
месте слайда. Отключить второй монитор во время показа → показ продолжается.

## 6. Android (вручную)

Показ на весь экран, листание касанием и свайпом, касание середины → «Выйти», системная
«Назад» выходит; кнопки и пункта «вид докладчика» нет.
