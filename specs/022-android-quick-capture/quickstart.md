# Quickstart: быстрый захват

## 1. Ядро

```bash
.specify/scripts/typsidian/gates.sh core     # capture_native, capture_wasm
```

## 2. Web — «Сегодня» и настройки

```bash
nix develop -c node scripts/dev/browser.mjs http://localhost:3000 \
    scripts/dev/scenarios/daily.mjs --opfs-vault --shot /tmp/daily.png
```

«Сегодня» → `дневник/<дата>.typ` создан, каретка в конце; второе нажатие — та же заметка;
‹ › через пропущенный день; смена вида названия в настройках D6 → новое имя, старые заметки на
месте. «Во входящие» с текстом → запись в конце `входящие.typ`.

## 3. Android (вручную)

`nix develop -c pnpm --filter mobile build`, установить APK.

1. Chrome → «Поделиться» → Typsidian → «Сохранить»: возврат в Chrome; в `входящие.typ` —
   ссылка с заголовком и временем. Касаний: 3 (SC-001).
2. Картинка из галереи → «Сегодня» → вложение и `#image` в ежедневной заметке.
3. Два захвата подряд — оба в порядке поступления.
4. Отозвать доступ к памяти → «Поделиться» → D3, «Ждут записи: 1»; вернуть доступ, открыть
   приложение → захват записан, очередь пуста.
5. Долгое нажатие на значок → «Сегодня» → ежедневная заметка с поднятой клавиатурой ≤2 с.
6. Заметка входящих открыта с несохранёнными правками → захват → правки и захват на месте.
