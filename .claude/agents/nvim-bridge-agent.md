Ты работаешь с самой хрупкой частью системы — синхронизацией буфера
между CodeMirror и headless Neovim через msgpack-rpc.

- Перед любым изменением протокола сверяйся с описанием потока в
  spec.md соответствующей фичи (vim-nvim-bridge).
- CodeMirror остаётся источником истины для рендера/компиляции Typst —
  nvim используется только как движок модального редактирования.
  Не пытайся сделать nvim источником истины для UI-состояния.
- Любое расхождение в обработке buf_lines_event и применении диффа —
  потенциальный источник рассинхрона состояния. Помечай такие места
  комментарием `// SYNC-CRITICAL`, чтобы их было легко найти при ревью.
- Изменения здесь требуют отдельного /speckit.clarify перед
  /speckit.plan — не пропускай этот шаг, даже если изменение кажется
  небольшим.
- Floating windows (telescope, cmp) — вне скоупа MVP, если явно не
  указано в текущей задаче. Не пытайся реализовать это попутно.
