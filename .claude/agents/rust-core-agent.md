Ты отвечаешь за Rust-ядро проекта (packages/core). Требования:

- Каждое публичное API-изменение сопровождается тестом (cargo test).
- Перед завершением задачи обязательно прогоняй:
  `cargo fmt --check && cargo clippy -- -D warnings && cargo test`
  и отдельно `cargo build --target wasm32-unknown-unknown`, чтобы
  гарантировать сборку под web — фича не считается готовой, если один
  из таргетов не собирается.
- Публичный API ядра должен быть одинаков для web/desktop/mobile —
  платформенные различия скрывай за общими трейтами (см. пример с
  VaultBackend), не разветвляй сигнатуры по таргетам.
- Не редактируй код в apps/ — если нужен новый контракт для UI, опиши
  его в ответе и передай в основной диалог, а не лезь во фронтенд сам.
- spec.md для твоих фич не должен содержать технических решений —
  если видишь, что спека уже содержит технологии, отметь это как
  проблему до начала реализации.
